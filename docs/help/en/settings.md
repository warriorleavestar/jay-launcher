# Settings

Settings come in nine groups: General, Appearance, Game defaults, Downloads and services, Storage, Privacy and security, Multiplayer, Experimental, About.

## How to
- Wide window: pick a group on the left; medium: a group menu at the top; narrow: the list of groups first, then one group.
- Search: press Ctrl+F, type the name of a setting, press Enter to jump to it.
- From anywhere, press Ctrl+K and type # followed by the setting's name.
- Changes are saved immediately; there is no Save button.

## If something goes wrong
- Cannot find a setting: search with Ctrl+F; results read "Group › Setting".

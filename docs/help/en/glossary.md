# Words in Jay

Short, plain meanings of the words Jay uses.

## Words
- **Instance**: one game setup with its own version, mods and worlds.
- **Loader**: what lets mods run, such as Fabric, Forge, NeoForge or Quilt.
- **Room**: your world plus a private way in for the friends you invite.
- **Invite**: the code you send a friend so they can knock on your room. Your address is not in it.
- **Safety code**: a code both sides see. If they are the same, nobody is in between.
- **Device code**: a code that points to this computer. Friends use it to find your room in public rooms.
- **Friend code**: lets someone ask to add you as a friend. It is not a device code and does not find your room.
- **Relay**: a server that passes data between two computers when they can't reach each other directly. It can see your IP address, not the content.
- **Connected directly / via relay**: whether your games talk straight to each other or through a relay.

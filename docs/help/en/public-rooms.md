# Public rooms

Public rooms come from public networks run by communities or friends. There is no ready-to-use public network yet, so add one first.

## How to
- In the multiplayer lobby, choose **Public** under "Where to play". If no public network is added yet, choose **Add a public network…** and paste the address you were given.
- Connect. The first time, Jay explains what others can see before anything is sent.
- Search with / , filter by version, and sort the list. F5 refreshes.
- To list your own room, connect to a public network, then pick **Public (password optional)** for "Who can come in" when you open the room. For a room that is already open, use **List it in Public rooms ›** in the room.
- Have a device code? Connect to the public network your friend uses, then find their room with the code.

## If something goes wrong
- For a child, public rooms can be turned off: see [For a child](help:child-mode).

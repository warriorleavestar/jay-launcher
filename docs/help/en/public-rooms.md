# Public rooms

Public rooms come from public networks run by communities or friends. Jay has no public network built in.

## How to
- Open **Multiplayer › Public rooms**. If no public network is added yet, choose **Add a public network…** and paste the address you were given.
- Connect. The first time, Jay explains what others can see before anything is sent.
- Search with / , filter by version, and sort the list. F5 refreshes.
- To list your own room, open it, then **List it in Public rooms ›** in the room.
- Have a friend code? Connect to the public network your friend uses, then find their room with the code.

## If something goes wrong
- For a child, public rooms can be turned off: see [For a child](help:child-mode).

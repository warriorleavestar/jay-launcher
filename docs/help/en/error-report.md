# Exporting an error report

An error report is one file with what a helper needs to understand a crash. You see what goes into it before you share it.

## How to
- Open the instance's **Logs** tab and choose **Export error report…**.
- The preview says what is in the report: the game and mod list, the last 2000 lines of the log, and the system and Java version.
- Jay has already removed account details other than the player name, tokens, your computer's user name and the user name in file paths.
- **Export to file…** or **Copy to clipboard**. Jay never sends it anywhere by itself.

# Jay collects no data: the network list

Jay has no telemetry, statistics, ads or remote switches. It goes online only in five cases, and the "About and privacy" page shows how each stands right now.

## The five cases
- Downloads you start: the game, mods, Java, modpacks, loaders, multiplayer components.
- Microsoft sign-in: signing in, refreshing it, your own skin.
- Modrinth / CurseForge: only while you use Discover or click "Check for updates".
- Checking for a new Jay: sends only the current version number to the address you set.
- Multiplayer: rooms, joining, public rooms, joining servers.

## How to
- Open [About and privacy](jay:about): each case has "Change ›", which goes straight to its setting.
- Everything kept on your computer is in the data folder; the page has **Open data folder**.

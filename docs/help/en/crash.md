# The game crashed

When a game crashes, the instance page shows a "last session" panel with the most likely cause and buttons that fix it on the spot.

## How to
- Open the instance. The panel shows **Most likely**, sometimes **Also possible**, and the evidence from the log.
- Use the button under the cause: **Give it more memory**, **Disable** a mod, **Turn shaders off**, **Choose a Java…** or **Repair game files**. Then start the game again.
- **Still not working?** offers [Help me fix…](help:fix-helper) and the log.

## If something goes wrong
- No known cause found: [export an error report](help:error-report) and send it to someone who knows.

# Checking the mods before you join

When you join a modded room, Jay compares your mods with the host's so the game doesn't crash on the way in.

## How to
- After you knock, the **Check the mods** card compares the lists. Jay only says they match after it has checked.
- It lists what you're missing, what is in another version, and what you have extra. Extras that only run on your side, like minimaps, are usually fine.
- **Sync the mods** fixes it: into a new instance (yours stays as it is) or straight into yours (replaced files go to Recently deleted). Files on Modrinth come from there; the rest the host sends, encrypted through the room.
- **Never mind, just join** goes in anyway. If the game crashes, the "last session" panel remembers this.

## If something goes wrong
- The host turned off mod syncing: ask the host for the modpack.

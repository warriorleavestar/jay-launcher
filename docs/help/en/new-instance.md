# New instance

Create a new game: pick a version and, if you want mods, a loader.

## How to
- Version: the latest release is selected. The chips at the top switch to snapshots and old versions.
- Loader: Fabric, Forge, NeoForge or Quilt. A loader that does not support the version is greyed out with the reason.
- **Jay loader**: Jay's own loader, last in the row. It builds on NeoForge or Forge for the chosen version and lets one instance mix mods made for Fabric, Forge and NeoForge (experimental). The name defaults to something like "1.21.1-Jay". Versions it doesn't run yet are greyed out with the ones it does.
- With an ordinary loader picked, the tick box "Use the universal loader to mix in mods from other loaders" sits under it, on supported versions only. You can turn it on or off later on the instance's Settings tab.
- Name: it must not match an existing instance.
- Click **Install**. You can also import a modpack file, or add another launcher's game folder.
- Esc closes the panel.

## If something goes wrong
- The install fails: usually a network problem; choose another route in [Settings › Download route](jay:settings#Source) and try again.

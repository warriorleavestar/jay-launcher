# Modpacks

A modpack is a whole set of mods and settings that makes a new instance.

## How to
- From a file: in the library choose **New instance**, then **Modpack file**, and pick a .mrpack or CurseForge .zip. Jay shows what is inside before anything is installed.
- Or drag the modpack file onto the Jay window.
- Online: in Discover, choose the Modpacks type and install one.
- Share your own: on the instance page choose **⋯ More › Export modpack…**, pick Modrinth (.mrpack) or CurseForge (.zip) and what to include.

## If something goes wrong
- Some CurseForge files can't be downloaded automatically; Jay lists them so you can download them by hand.

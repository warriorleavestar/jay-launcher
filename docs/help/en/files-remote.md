# Sending files and remote control

In a room you can send a file to someone, or ask to control their computer to help them. Both always need the other person to say yes.

## How to
- Send a file: choose a person, then send it in your private chat. They see a locked card and decide.
- A received file is only saved to Downloads/Jay. Jay never opens it by itself, and warns you when it is a program.
- Remote control: the other person must accept every time. While it runs their screen has a red border, and Ctrl+Shift+F12 stops it at once.

## If something goes wrong
- Remote control is only for people you trust. Nobody from Jay will ever ask you for it.
- For a child, remote control can be turned off: see [For a child](help:child-mode).

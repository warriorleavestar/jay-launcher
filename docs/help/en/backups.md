# Backing up and restoring worlds

A backup is a copy of a world you can go back to, for example before trying a big change.

## How to
- Open an instance and choose **Worlds**. Select a world and press B, or use **Back up**. The backup runs in the activity centre.
- Press Enter on a world to open its panel. Backups are listed from newest to oldest.
- **Restore…** asks once more and says which backup you picked. The world as it is now is backed up first, so nothing is lost.

## If something goes wrong
- A world can't be restored while the game is running. Close the game first.

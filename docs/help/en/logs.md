# Reading logs

Logs are what the game writes while it runs. When the game crashes or will not start, the log usually shows why.

## How to
- Open an instance's Logs tab and pick a session (newest first).
- F8 jumps to the next error, Shift+F8 to the previous one.
- Filter to errors or warnings; repeated warnings fold into one line marked ×N.
- Export an error report: you see exactly what will be exported first; the report never contains your computer's user name.

## If something goes wrong
- Hard to read: start with the "Crash diagnosis" line at the top; it names the most likely cause in plain words.

# Recently deleted

Mods, packs, worlds and instances you delete in Jay aren't gone at once. They wait in Recently deleted, so you can bring them back.

## How to
- Open **Settings** and find **Recently deleted**. Each item shows what it is, which instance it came from and how many days are left.
- **Restore** puts it back where it was.
- **Keep for** sets how many days things stay.
- **Delete forever** and **Empty…** ask once more, because they can't be undone.

## If something goes wrong
- Can't restore because something with the same name is there: rename or remove that first.
- A mod from a deleted instance: restore the instance first.

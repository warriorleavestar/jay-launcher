# Keyboard shortcuts

Everything can be done with the mouse; these are the matching shortcuts.

## Everywhere
- Ctrl+K: command palette (instances, settings, pages).
- Ctrl+1 / Ctrl+2 / Ctrl+3: Library / Discover / Multiplayer.
- Ctrl+,: Settings.
- Ctrl+J: Activity.
- F1: help for this page; Shift+F1: help center.
- Alt+← / Alt+→: back / forward.

## On a page
- Ctrl+F: search this page.
- Esc: close a drawer or panel, or clear a search.
- F8 / Shift+F8: next / previous error in a log.

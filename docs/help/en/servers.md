# Servers

The Servers tab is for joining servers your friends run, and for running a Minecraft server yourself.

## How to
- Join a server: paste the server invite (it starts with JAYS2-) in the box at the top of Multiplayer. Jay takes it to Servers.
- Run your own: follow the steps **Address › Prepare the server › Start › Invite**. Jay downloads the server from the official source, checks it, and gets Java if needed.
- While it runs you can type commands in the console. Enter sends, ↑ and ↓ bring back earlier ones.

## If something goes wrong
- Friends can't reach your server: your router or firewall must allow the port you entered in the first step.

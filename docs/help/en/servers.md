# Servers

An always-on server can be used two ways: join one a friend runs, or run a Minecraft server yourself.

## How to
- Join a server: paste the server invite (it starts with JAYS2-) in the box at the top of Multiplayer and click **Join and save**. A sealed invite also asks for its passphrase. Saved servers are under **Servers** in "Where to play"; click **Play** there next time.
- Run your own: under the Open a room card, click **Open an always-on server…** and follow the steps **Address › Prepare the server › Start › Invite**. Jay downloads the server from the official source, checks it, and gets Java if needed.
- While it runs you can type commands in the console. Enter sends, ↑ and ↓ bring back earlier ones.

## If something goes wrong
- Friends can't reach your server: your router or firewall must allow the port you entered in the first step.

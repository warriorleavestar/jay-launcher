# 公開ルーム

公開ルームは、コミュニティやフレンドが運営する公開ネットワークにあります。今すぐ使える公開ネットワークはまだないので、先に 1 つ追加してください。

## 使い方
- **マルチプレイ › 公開ルーム** を開きます。まだ公開ネットワークがなければ **公開ネットワークを追加…** を押し、教えてもらったアドレスを貼り付けます。
- 接続します。初回は、何かを送る前に、ほかの人に何が見えるかを Jay が説明します。
- / で検索、バージョンで絞り込み、並べ替えができます。F5 で更新。
- 自分のルームを載せるには、ルームを開いてからルームの中で **公開ルームに載せる ›** を押します。
- デバイスコードがあるとき：フレンドが使っている公開ネットワークに接続してから、コードでルームを探します。

## うまくいかないとき
- 子ども向けに公開ルームをオフにできます：[子どもが使うとき](help:child-mode)を見てください。

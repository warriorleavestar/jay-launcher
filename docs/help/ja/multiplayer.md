# マルチプレイ

フレンドと遊ぶ：ルームを開いて招待を送ります。フレンドがコードを貼ってノックし、あなたが許可すると入れます。

![マルチプレイのロビー：一番上が参加、その下に「ルームを開く」と「遊ぶ場所」](shot:multiplayer-lobby)

マルチプレイのページにタブはありません。ルームにいないときはロビー、入るとルームになります。

## 使い方
- 参加する：もらったコードを一番上の欄に貼り、ボタンを押して許可を待ちます。ルームの招待、サーバー招待、フレンドコード、ネットワークのアドレスは、すべてこの 1 つの欄に貼ります。ボタンには、押すと何をするかが書かれます。
- ルームを開く：**ルームを開く** を押すだけです。4 つの選択は変えなくても開けます。入れる人（招待した人だけ、フレンドは直接ノックできる、公開）、つなぎ方（自動、中継のみ、サーバーなし）、保護（標準、強化、最高）、範囲（このゲームだけ、LAN 全体）。選べない項目には、その下に理由が書かれます。
- 中継のみ：ルームの人どうしで IP アドレスは見えません。少し遅くなります。
- サーバーなし：ボタンが **暗号化した直接コードを作る** に変わります。コードを送り、合言葉は別の方法で伝えてください。
- 遊ぶ場所：フレンドに招待されたルーム、公開ルーム、保存したサーバーが 1 つのリストに並びます。**すべて / フレンド / 公開 / サーバー** で絞り込めます。
- 誰かがノックした：ルームにカードが出ます。**許可** か **断る**（Alt+Y / Alt+N）。
- 安全コード：お互いに同じ安全コードが見えていれば、間に誰かが成りすましていません。
- 初回はマルチプレイ用のコンポーネントが必要です。ボタンに「先にマルチプレイ用コンポーネントを入れる」と出るので、1 回押してインストールし、もう 1 回押すとルームを開くか参加します。

## うまくいかないとき
- つながらない：「ネットワークを確認」を実行すると、どの段階で止まっているかがわかります。
- 子ども向け：リモートサポートや公開ネットワークなどをオフにできます。[子ども向け](help:child-mode) を見てください。

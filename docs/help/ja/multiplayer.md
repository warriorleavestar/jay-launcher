# マルチプレイ

フレンドと遊ぶ：ルームを開いて招待を送ります。フレンドがコードを貼ってノックし、あなたが許可すると入れます。

![マルチプレイのロビー：一番上が参加、その下に「ルームを開く」と「遊ぶ場所」](shot:multiplayer-lobby)

マルチプレイのページにタブはありません。ルームにいないときはロビー、入るとルームになります。

## 使い方
- 参加する：もらったコードを一番上の欄に貼り、ボタンを押して許可を待ちます。ルームの招待、サーバー招待、フレンドコード、ネットワークのアドレスは、すべてこの 1 つの欄に貼ります。ボタンには、押すと何をするかが書かれます。
- ルームを開く：**ルームを開く** を押すだけです。4 つの選択は変えなくても開けます。入れる人（招待した人だけ、フレンドは直接ノックできる、公開）、つなぎ方（自動、中継のみ、サーバーなし）、保護（標準、強化、最高）、範囲（このゲームだけ、LAN 全体）。選べない項目には、その下に理由が書かれます。
- 中継のみ：すべて中継を通すので、ルームの人どうしで IP アドレスは見えません。少し遅くなります。Jay が古くてこの設定に対応していないフレンドは入れないので、先に更新してもらってください。
- サーバーなし：ボタンが **暗号化した直接コードを作る** に変わります。コードを送り、合言葉は別の方法で伝えてください。2 台のパソコンが直接つながり、つながらなくても中継には切り替えません。あなたのアドレスを調べるために、Jay は設定 › ネットワークにある STUN サーバーに問い合わせます。STUN サーバーにはあなたの IP アドレスが見えます。
- 遊ぶ場所：フレンドに招待されたルーム、公開ルーム、保存したサーバーが 1 つのリストに並びます。**すべて / フレンド / 公開 / サーバー** で絞り込めます。
- 誰かがノックした：ルームにカードが出ます。**入れる** か **拒否**（Alt+Y / Alt+N）。既定は **拒否** です。
- 安全コード：お互いに同じ安全コードが見えていれば、間に誰かが成りすましていません。
- 初回はマルチプレイ用のコンポーネントが必要です。ボタンに「先にマルチプレイ用コンポーネントを入れる」と出るので、1 回押してインストールし、もう 1 回押すとルームを開くか参加します。

## ルームの中
- 上にはルーム名、人数、接続マーク（「直接接続 · 18 ms」または「中継経由 · 82 ms」）が出ます。それぞれの顔の下の細い線は、直接か中継経由かを表します。確認済みのフレンドの顔にはチェックが付きます。
- 【招待】：有効期間（10 分、1 日、30 日）と使える回数（1 回、無制限）を選び、【招待を作成】を押します。招待は小さなカードになり、【コピー】か【フレンドに送る】ができます。コードは【表示】を押したときだけ見えます。回数無制限の招待は、ノックのたびに必ずあなたに確認します。30 日の招待はこれから開くどのルームでも使え（「サーバーなし」のルームを除く。いま開いているルームでは、ほかの招待が出ていないときだけすぐ使えます。どちらかはカードに書かれます）、いつでも無効にできます。
- 接続マークを押すと「誰に何が見えるか」が開きます。あなたの IP が誰に見え、内容が誰に見えるかを書いた決まった表です。いまのあなたに当てはまる行には「いま」と書かれます。下に「中継のみ」のスイッチがあります。オンにするとルームの人からあなたの IP は見えません。遅延は少し増えます。切り替えるとルームにつなぎ直します。オフのあいだは、たまたま中継経由でも Jay が直接接続を試し続けるため、ルームの人はあなたの IP を知ることができます。どのルームでもそうしたいときは、設定 › マルチプレイの「いつも中継のみにする」をオンにします。
- 人を押すと、安全コード、フレンドかどうか、つながり方が見えます。「この人と共有」にはリモートサポート、ゲームの転送、自分の回線を使わせる、の 3 つがあり、どれもオンにする前に確認します。
- 【ゲームに入る】：参加した人が押すと、選んだインスタンスでそのままフレンドのワールドに入ります。

## うまくいかないとき
- つながらない：**接続がうまくいかない？**（Ctrl+Shift+D）を開いて **ネットワークを診断** を押すと、どの段階で止まっているかがわかります。
- 子ども向け：リモートサポートや公開ネットワークなどをオフにできます。[子ども向け](help:child-mode) を見てください。

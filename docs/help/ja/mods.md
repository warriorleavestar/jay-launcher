# MOD

インスタンスの MOD タブには、入っている MOD がすべて並びます。検索したり、削除せずにオフにしたり、更新したりできます。

## 使い方
- インスタンスを開き、**MOD** タブを選びます（Alt+2）。
- 検索欄に入力するか、チップで絞ります：**すべて**、**オフ**、**更新あり**、**問題あり**。
- MOD をクリックすると、右側に詳細が出ます。
- いくつかにチェックを入れると一括バーが出ます。まとめてオフ、オン、削除ができ、すぐ後に **元に戻す** があります。
- **Mod を追加 › オンラインで探す…** は「見つける」を開き、このインスタンスに合う MOD だけを表示します。.jar ファイルをウィンドウにドラッグしても追加できます。
- 更新が見つかると **すべて更新** が出ます。

## うまくいかないとき
- 削除した MOD は数日間[最近削除したもの](help:recycle)に残ります。
- MOD を入れたらクラッシュする：[直すのを手伝って…](help:fix-helper)を見てください。

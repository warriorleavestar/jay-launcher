# ファイル送信とリモート操作

部屋の中では、誰かにファイルを送ったり、手伝うために相手のパソコンの操作を頼んだりできます。どちらも必ず相手の許可が要ります。

## 使い方
- ファイルを送る：相手を選び、個別チャットで送ります。相手にはロックされたカードが出て、相手が決めます。
- 受け取ったファイルは「ダウンロード/Jay」に保存されるだけです。Jay が勝手に開くことはなく、プログラムのときは知らせます。
- リモート操作：毎回相手の許可が要ります。操作中は相手の画面に赤い枠が出て、Ctrl+Shift+F12 ですぐに止められます。

## うまくいかないとき
- リモート操作は信頼できる人だけに。Jay のスタッフがそれを求めることは決してありません。
- 子ども向けにリモート操作をオフにできます：[子どもが使うとき](help:child-mode)を見てください。

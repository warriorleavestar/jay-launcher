# ファイル送信とリモートサポート

フレンドやルームの人に、ファイル、ワールド、MOD リスト、スクリーンショット、ログ、フォルダーを送れます。毎回、相手が受け取りを押してからです。手伝うために相手のパソコンの操作を頼むこともでき、これも相手の許可が要ります。

## ファイルを送る
- フレンドとの会話で、入力欄の左のクリップを押して送るものを選びます。ファイルを会話にドラッグしても送れます。
- ルームでは人を押して **ファイルを送る** を押します。インスタンスの「ワールド」タブでは、各ワールドの行に **フレンドに送る** があります。
- ワールドとフォルダーは先に 1 つの圧縮ファイルにまとめます。ゲームのワールドはそのままです。MOD リストは名前とバージョンだけを送り、MOD 本体は送りません。ログは送る前に伏せ字にします（パソコンのユーザー名、トークン、メールアドレス）。
- 会話に出るカードに、進み具合、直接か中継経由か、速度が出ます。**キャンセル** できます。
- フレンドが同じルームにいないときは、このパソコンで待ち、同じルームに入ると自動で始まります。途中で切れた送信は、次に会ったとき続きから送ります。

## ファイルを受け取る
- 誰かが送ってくると、上のリクエストバーに、誰か、確認済みのフレンドか、どんな種類かが出ます。既定は **拒否** です。Alt+Y で受け取り、Alt+N で拒否します。5 分答えないと受け取らなかった扱いです。
- 受け取ったファイルは「ダウンロード/Jay」に保存されるだけです（[設定 › マルチプレイ › ファイル](jay:settings#FilesFolder) で変えられます）。Jay が勝手に開くことはなく、プログラムのときは知らせます。
- ワールドを受け取ると、カードに **インスタンスに取り込む** があります。MOD リストには **Mod を比べる** があり、足りない数と違うバージョンの数が出ます。

## リモートサポート
- ルームで人を押し、「この人と共有」で画面を見せてもらうよう頼みます。毎回相手の許可が要ります。操作中は相手の画面に赤い枠が出て、Ctrl+Shift+F12 ですぐに止められます。

## 知っておくと良いこと
- ファイルはエンドツーエンドで暗号化され、ホストや中継には中身が見えません。
- 設定 › マルチプレイ › ファイルで、確認済みのフレンドからのファイルを聞かずに受け取る（既定はオフ、プログラムは必ず聞きます）ことや、速度の制限ができます。
- リモートサポートは信頼できる人だけに。Jay のスタッフがそれを求めることは決してありません。子ども向けでは、ファイルはフレンドからだけ受け取り、リモートサポートをオフにできます：[子どもが使うとき](help:child-mode)を見てください。

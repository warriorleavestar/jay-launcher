# 見つける：MOD、MOD パック、リソースパック、シェーダー

Modrinth と CurseForge を検索して、インスタンスに入れます。

## 使い方
- 上のチップで種類を、切り替えボタンで提供元を選びます。
- 結果の **＋ 追加予定** を押す（または Space）と追加予定バーに入ります。**N 個インストール** でまとめて入れます。前提 MOD も一緒に入ります。
- 結果を押すと詳細：広い画面では右の列、狭い画面では右から引き出しで出ます。Esc で閉じます。

## うまくいかないとき
- CurseForge で何も見つからない：公式のデスクトップ版にはキーが入っています。それ以外（自分でビルドした版、Android 版）では、自分の CurseForge キーを [設定 › ダウンロードとサービス](jay:settings#CurseForgeKey) に入れてください。
- Jay が Modrinth / CurseForge につなぐのは、このページを使っているときか「更新を確認」を押したときだけです。裏では調べません。

# Jay のことば

Jay で使うことばを、ひとことで説明します。

## ことば
- **インスタンス**：バージョン、MOD、ワールドを持つ、ひとつのゲーム環境。
- **ローダー**：MOD を動かすもの。Fabric、Forge、NeoForge、Quilt など。
- **部屋（ルーム）**：あなたのワールドと、招待した友だちだけが通れる道。
- **招待コード**：友だちに送るコード。これであなたの部屋にノックします。
- **安全コード**：両方に表示されるコード。同じなら、間に誰もいません。
- **フレンドコード**：公開ルームで友だちの部屋を探すコード。
- **中継サーバー**：2 台のパソコンが直接つながらないとき、間をつなぐサーバー。
- **直接接続 / 中継経由**：ゲーム同士が直接やりとりしているか、中継サーバーを通っているか。

# Jay のことば

Jay で使うことばを、ひとことで説明します。

## ことば
- **インスタンス**：バージョン、MOD、ワールドを持つ、ひとつのゲーム環境。
- **ローダー**：MOD を動かすもの。Fabric、Forge、NeoForge、Quilt など。
- **ルーム**：あなたのワールドと、招待したフレンドだけが通れる道。
- **招待**：フレンドに送るコード。これであなたのルームにノックします。あなたのアドレスは入っていません。
- **安全コード**：両方に表示されるコード。同じなら、間に誰もいません。
- **デバイスコード**：このパソコンを指すコード。フレンドが公開ルームであなたのルームを探すのに使います。
- **フレンドコード**：フレンド追加を申請してもらうためのコード。デバイスコードではなく、ルームは探せません。
- **中継**：2 台のパソコンが直接つながらないとき、データを受け渡すサーバー。あなたの IP は見えますが、内容は見えません。
- **直接接続 / 中継経由**：ゲーム同士が直接やりとりしているか、中継を通っているか。

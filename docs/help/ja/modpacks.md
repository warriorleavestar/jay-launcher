# MODパック

MODパックは MOD と設定のひとそろいで、新しいインスタンスになります。

## 使い方
- ファイルから：ライブラリで **新しいインスタンス** を選び、「Modpack ファイル」で .mrpack か CurseForge の .zip を選びます。インストール前に中身を確認できます。
- MODパックのファイルを Jay のウィンドウにドラッグしても同じです。
- オンライン：「見つける」で MODパックの種類を選んでインストールします。
- 自分のものを共有：インスタンスのページで **⋯ その他 › MODパックをエクスポート…** を選び、Modrinth（.mrpack）か CurseForge（.zip）と、含めるものを選びます。

## うまくいかないとき
- CurseForge のファイルには自動でダウンロードできないものがあります。Jay が一覧にするので、手動でダウンロードしてください。

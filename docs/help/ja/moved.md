# どこに移った？

Jay のレイアウトは、ライブラリ、見つける、マルチプレイ、フレンドの 4 つです。前のページの行き先はこちら。

## 前のページ → 新しい場所
- **起動** → ライブラリ：各インスタンスの大きな開始ボタン。
- **ダウンロード** → ライブラリの **新しいインスタンス**、MOD と MODパックは「見つける」。
- **リソース** → 見つける。
- **インスタンス** → ライブラリ。インスタンスをクリックすると開きます。
- **ログ** → 各インスタンスのログタブ。
- **ツールボックス** → クリーンアップは 設定 › ストレージ、Java のダウンロードは 設定 › ゲームの既定、更新確認は 設定 › 情報。
- **アカウント** → **自分**：左下のアバターを押します。フレンドコードと自分のデバイスもここにあります。
- **ライト/ダークと言語**（以前はアバターのメニュー）→ **自分** › 外観。設定でもこれまでどおり変えられます。
- **フレンド**（以前はマルチプレイ設定の中）→ サイドバーの「フレンド」。追加、バックアップ、復元もそこにあります。
- **信頼する人**（以前はマルチプレイ設定の一覧）→ フレンドのページで、1 人ずつの「ノックされたらそのまま入れる」スイッチ。
- Jay がいま使っているネットワーク → 右上のネットワーク状態。どのページにもあります。
- Ctrl+K で何でも探せます。前のページ名でも見つかります。

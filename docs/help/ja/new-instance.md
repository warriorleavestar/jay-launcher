# 新しいインスタンス

新しいゲームを作ります。バージョンを選び、MOD を使うならローダーも選びます。

## 使い方
- バージョン：最新のリリースが選ばれています。上のチップでスナップショットや古いバージョンに切り替えられます。
- ローダー：Fabric、Forge、NeoForge、Quilt。そのバージョンに対応しないものは灰色になり、理由が書かれます。
- **Jay ローダー**：Jay 独自のローダーで、列の最後にあります。選んだバージョンの NeoForge か Forge をベースにし、1 つのインスタンスで Fabric・Forge・NeoForge 向けの MOD を混ぜて使えます（実験的）。名前は「1.21.1-Jay」のようになります。まだ対応していないバージョンでは灰色になり、対応しているバージョンが書かれます。
- 普通のローダーを選んだときは、下に「汎用ローダーで別のローダーのMODも混ぜて入れる」のチェックがあり、対応バージョンでだけ選べます。あとでインスタンスの「設定」タブでも切り替えられます。
- 名前：既存のインスタンスと同じ名前は使えません。
- **インストール** を押します。MOD パックのファイルを読み込んだり、ほかのランチャーのゲームフォルダーを追加したりもできます。
- Esc でパネルを閉じます。

## うまくいかないとき
- インストールに失敗する：多くはネットワークの問題です。[設定 › ダウンロード経路](jay:settings#Source) で別の経路を選んでもう一度試してください。

# ライト・ダークとテーマパック

Jay はシステムに合わせることも、いつもライトやダークにすることもできます。テーマパックは色、フォント、角の丸みを変えます。

![設定 › 外観](shot:appearance)

## 使い方
- いちばん早いのは、サイドバー下のアバターをクリックして **自分** を開き、**外観** でライト／ダークを選ぶ方法です。言語もそこで変えられます。
- **設定 › 外観 › テーマ**：システムに合わせる、ライト、ダーク。
- テーマパック：.jaytheme ファイルを読み込むか、ウィンドウにドラッグします。すぐに反映されます。
- 自分の画像でテーマを作る：**設定 › 外観 › 画像でテーマを作る…** で、背景、サイドバー、キャラクター、バナーに画像を選びます（ウィンドウにドラッグしても入れられます）。色は画像から Jay が選び、プレビューで確かめられます。**使う** ですぐ切り替わり、**.jaytheme で保存して共有** で友だちに送れるテーマパックになります。キャラクターはページの後ろにあるのでボタンを隠さず、狭いウィンドウでは非表示になります。
- 組み込み：**Jay クラシックアンバー** と **ハイコントラスト**。削除できません。
- 古い形式のテーマパックは読み込むときに自動で更新され、カードにその印が出ます。**作者向けにコピー** で変わった内容をコピーできます。
- テーマパックで安全の表示やプライバシーの文は変えられません。

## うまくいかないとき
- テーマパックのせいで Jay が開かなくなった：次の起動では Jay が自動で標準の見た目を使います。--default-theme を付けて起動することもできます。

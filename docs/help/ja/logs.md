# ログを見る

ログはゲームが動いている間に書く記録です。クラッシュしたり起動しなかったりしたとき、たいていログに理由があります。

## 使い方
- インスタンスのログタブを開き、プレイ記録を選びます（新しいものが先）。
- F8 で次のエラー、Shift+F8 で前のエラーへ。
- エラーや警告だけに絞れます。同じ警告は 1 行にまとめて ×N と表示します。
- エラーレポートの書き出し：書き出す内容を先に確認できます。レポートにコンピューターのユーザー名は入りません。

## うまくいかないとき
- 読み方がわからない：まず上の「クラッシュ診断」の行を見てください。いちばんありそうな原因をやさしく書いています。

# 入る前に MOD を確かめる

MOD 入りのルームに参加するとき、Jay はあなたの MOD とホストの MOD を比べて、入った途端にクラッシュしないようにします。

## 使い方
- ノックのあと、「MOD を確かめる」カードが一覧を比べます。比べ終わるまで「同じ」とは言いません。
- 足りないもの、バージョン違い、あなたにだけあるものが出ます。ミニマップのように自分の側だけで動く MOD は、たいてい問題ありません。
- **MOD をそろえる** で直せます：新しいインスタンスに（今のものはそのまま）、または今のインスタンスを直接（置き換えたファイルは最近削除したものへ）。Modrinth にあるものはそこから、それ以外はホストがルーム経由で暗号化して送ります。
- **気にせず入る** でそのまま入れます。クラッシュしたら「前回」パネルがこのことを覚えています。

## うまくいかないとき
- ホストが MOD の同期をオフにしている：ホストに MODパックを送ってもらってください。

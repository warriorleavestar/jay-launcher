# リソースパックとシェーダー

リソースパックはテクスチャと音を、シェーダーは光の当たり方を変えます。Jay のパック一覧はゲーム内の「リソースパック」画面と同じものです。

## 使い方
- インスタンスを開き、**リソースパック** を選びます。**オン** と **オフ** の 2 列があり、上にあるものが優先されます。
- スペースで選んだパックをオン／オフ、Alt+↑ / Alt+↓ で移動します。
- 古いバージョン用か新しいバージョン用かはタグでわかります。たいてい動きますが、一部のテクスチャがおかしく見えることがあります。
- シェーダーには Iris MOD が必要です。入っていないと **シェーダー** タブにバナーと **Iris を入れる** が出ます。
- シェーダーを選ぶとそれを使います。**シェーダーなし** も選べます。

## うまくいかないとき
- シェーダーを入れるとクラッシュする：「前回」パネルで次の起動だけシェーダーをオフにできます。シェーダーパックは残ります。
- 削除したパックは[最近削除したもの](help:recycle)にあります。

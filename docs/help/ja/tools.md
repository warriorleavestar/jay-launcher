# ツールボックス

あまり使わないけれど、ときどき役に立つものがあります。Jay の更新確認、ゲームファイルの修復、キャッシュの削除など。

## 使い方
- [設定 › ツール](jay:settings#OpenTools) から、または設定の上の「ツールボックス」タブから開きます。
- 各ツールは何をするか書いてあります。削除するものは先に確認します。

## うまくいかないとき
- 更新確認が何もしない：先に [設定 › ダウンロードとサービス](jay:settings#UpdateFeed) で更新先を入れてください。入れなければ Jay はこのためにネットにつなぎません。

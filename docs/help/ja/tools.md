# クリーンアップ、Java、更新

以前のツールボックスはなくなり、中のものはそれぞれ探しそうな場所に移りました。

## 使い方
- ゲームの不要ファイルを削除：[設定 › ストレージ](jay:settings#Junk)。**スキャン**で削除できるものとサイズが並びます。選んでから削除します。
- Java を手動でダウンロード：[設定 › ゲームの既定](jay:settings#JavaDownload)。ふだんは Jay が合う Java を自動で入れます。
- Jay の更新を確認：[設定 › 情報](jay:settings#CheckUpdate)。
- ダウンロードを試す：マルチプレイで「接続がうまくいかない？」を開き、**ファイルをダウンロード**を広げます。

## うまくいかないとき
- 更新確認は Jay 公式のリリースに問い合わせます。[設定 › ダウンロードとサービス](jay:settings#UpdateFeed) で自分の更新先に変えられます。新しく入れた Jay は 1 日 1 回自分でも確認します（旧版から更新した場合はオフのままで、[設定 › 情報](jay:settings#AutoUpdate) でオン・オフを切り替えられます）。信任者が署名した新しいバージョンを知らせるだけで、ダウンロードはしません。

# インスタンスの詳細

インスタンスは独立した 1 つのゲームです。バージョン、ローダー、MOD、ワールド、設定がそれぞれ別になっています。

## 使い方
- 遊ぶ：右上の琥珀色の **プレイ** を押します。
- タブ：概要、MOD、ワールド、リソースパック、シェーダーパック、サーバー、スクリーンショット、ログ、設定。Alt+数字 か Ctrl+Tab で切り替えます。
- MOD を追加：MOD タブで **＋ MOD を追加** を押すと、このインスタンスに合う MOD だけを「見つける」で表示します。
- 前回クラッシュした：概要に「前回」パネルが出ます。中の修正ボタン（メモリ調整、MOD を無効化、シェーダーをオフ）を押してください。

## うまくいかないとき
- 起動しない：ログタブを開いて F8 で最初のエラーへ。または「前回」パネルの **直すのを手伝って…** を押します。

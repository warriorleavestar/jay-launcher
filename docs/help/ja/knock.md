# ノックと安全コード

招待を持った人があなたの部屋に入るときは、まずノックします。入れるかどうかはあなたが決めます。

## 使い方
- ノックが来ると、相手の名前と安全コードが書かれたロックされたカードが出ます。最初のフォーカスは **拒否** なので、Enter でうっかり入れてしまうことはありません。
- 友だちに画面の安全コードを読み上げてもらい、完全に同じときだけ入れます。
- Alt+Y で入れる、Alt+N で拒否。ノックはリクエストバーと最前面の小さなウィンドウにも出て、どこで答えても同じです。
- **ルーム設定** でノックを待つ時間を選べます：2 分、10 分、答えるまで。

## うまくいかないとき
- 1 文字でも違う：拒否して、もう一度ノックしてもらいます。誰かが間に入っているかもしれません。
- 練習したいとき：ロビー下の **一度練習する ›** で、コードが合わないノックを体験できます。

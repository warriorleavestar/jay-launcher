# キーボードショートカット

すべてマウスで操作できます。対応するショートカットは次のとおりです。

## どこでも
- Ctrl+K：コマンドパレット（インスタンス、設定、ページ）。
- Ctrl+1 / Ctrl+2 / Ctrl+3 / Ctrl+4：ライブラリ / 見つける / マルチプレイ / フレンド。
- Ctrl+,：設定。
- Ctrl+J：アクティビティ。
- F1：このページのヘルプ。Shift+F1：ヘルプセンター。
- Alt+← / Alt+→：戻る / 進む。

## ページの中で
- Ctrl+F：このページを検索。
- Esc：引き出しやパネルを閉じる、検索を消す。
- F8 / Shift+F8：ログで次 / 前のエラーへ。

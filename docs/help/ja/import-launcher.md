# ほかのランチャーから移る

ほかのランチャーのゲームフォルダーにあるインスタンスを、移動もコピーもせずにそのまま遊べます。

## 使い方
- ライブラリで **新しいインスタンス** を選び、「ほかのランチャーから」を選びます。見つかったゲームフォルダーが並びます。
- **このフォルダーを使う** を押します。一覧にないときは **フォルダーを選ぶ…**。
- インスタンスはその場所のまま遊びます。個別のフォルダーはそれぞれの設定を保ちます。
- 初回起動のガイドも見つけたゲームを表示し、**ライブラリに追加** で同じことができます。

## うまくいかないとき
- 何も見つからない：自分でフォルダー（versions が入っているもの）を選んでください。

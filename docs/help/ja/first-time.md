# はじめて Jay を使う

Jay は Minecraft Java 版のランチャーです。はじめて開くと 2 ステップのウィザードが出ます。言語を選んでアカウントを追加し、次にどこから遊ぶかを選びます。

## 使い方
- ステップ 1：右上で言語を変えられます。名前を入れてオフラインアカウントを追加するか、**Microsoft でサインイン** を押します。
- ステップ 2：最新のリリースが選ばれています。**インストールして遊ぶ** を押します。「別のバージョンを選ぶ」もできます。
- いつでも **スキップ** できます。あとで [ライブラリ](jay:library) の **新しいインスタンス** から同じようにインストールできます。

## うまくいかないとき
- 名前が使えない：英字・数字・アンダースコアで 3〜16 文字にしてください。
- インストールが遅い：[設定 › ダウンロード元](jay:settings#Source) で別のダウンロード元を選んでください。

# 子ども向け（保護者の方へ）

「子ども向け」をオンにすると、Jay のマルチプレイが慎重になり、子どもが一人で遊びやすくなります。

## 使い方
- [設定 › プライバシーとセキュリティ › 子ども向け](jay:settings#ChildMode) を開き、メインのスイッチをオンにします。下の 6 項目が一緒にオンになり、個別に変えられます。
- リモートサポートをオフ：誰もこのコンピューターを見たり操作したりする依頼ができません。
- 公開ルームと公開ネットワークを使わない：招待でフレンドとだけ遊べます。
- 「自分経由 / 相手経由」の通信を許可しない。
- フレンドからのファイルだけ受け取る：ほかの人からのファイルは断ります。
- 誰かがノックしたら必ず確認する：フレンドでも許可が必要です。
- 通知に名前や内容を出さない。

## 知っておくこと
- 保護者パスワードはありません。設定ファイルを書き換える子どもは止められず、かえって誤った安心感を与えるからです。設定に最終変更の時刻が出るので、変えられたかどうかがわかります。
- 知らない人がノックしたり、ファイルを送ってきたり、リモートサポートを求めてきたりしたら、**断る** を押してあなたに知らせるよう教えてください。

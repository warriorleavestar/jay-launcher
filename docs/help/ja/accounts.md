# アカウント：Microsoft、オフライン、スキンサイト

アカウントで、ゲーム内の名前とスキン、正規版のサーバーに入れるかどうかが決まります。

## 使い方
- Microsoft アカウント：**Microsoft でサインイン** を押し、ブラウザーでサインインします。
- オフラインアカウント：名前だけ。シングルプレイや LAN 向けです。
- スキンサイトのアカウント：スキンサイトのアドレス、アカウント、パスワードを入れます。
- 切り替え：左下のアバターを押してアカウントを選びます。

## うまくいかないとき
- Microsoft のサインインに失敗する：コンピューターの時刻が正しいか確認してください。子どもの Microsoft アカウントは、保護者が Xbox のファミリー設定でマルチプレイを許可する必要があります。
- サインイン情報はこのコンピューターにだけ、暗号化して保存されます。

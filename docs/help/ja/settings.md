# 設定

設定は 10 のグループに分かれています：一般、外観、ゲームの既定、ダウンロードとサービス、ストレージ、プライバシーとセキュリティ、マルチプレイ、ツール、実験的、Jay について。

## 使い方
- 広い画面は左でグループを選びます。少し狭いと上のメニュー、いちばん狭いとまずグループの一覧が出ます。
- 検索：Ctrl+F で設定名を入力し、Enter でその場所へ。
- どこからでも Ctrl+K を押して # と設定名を入力できます。
- 変更はすぐ保存されます。保存ボタンはありません。

## うまくいかないとき
- 設定が見つからない：Ctrl+F で検索してください。結果は「グループ › 設定」と表示されます。

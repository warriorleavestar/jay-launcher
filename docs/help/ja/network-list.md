# Jay はデータを集めません：ネット接続の一覧

Jay にはテレメトリ、統計、広告、リモートスイッチがありません。ネットにつなぐのは 5 つの場合だけで、「Jay について・プライバシー」のページにそれぞれの今の状態が出ます。

## 5 つの場合
- あなたが始めたダウンロード：ゲーム、MOD、Java、MOD パック、ローダー、マルチプレイ部品。
- Microsoft サインイン：サインインとその更新、自分のスキン。
- Modrinth / CurseForge：「見つける」を使っているときか「更新を確認」を押したときだけ。
- Jay の更新チェック：1 日 1 回（オフにできます）と「更新を確認」を押したときに、Jay 公式のリリースか入れた更新先に最新バージョンを問い合わせます。知らせるだけで、ダウンロードはしません。
- マルチプレイ：ルーム、参加、公開ルーム、サーバーへの参加。

## 使い方
- [Jay について・プライバシー](jay:about) を開きます。各項目の「変更 ›」で、その設定へ直接移動します。
- このコンピューターに保存されるものはデータフォルダーにあります。ページに **データフォルダーを開く** があります。

# ライブラリ

ライブラリは Jay のホームです。インストールしたゲーム（インスタンス）がすべてここにあり、最近遊んだものが先に並びます。

![ライブラリ：上に「続きから遊ぶ」、下にインスタンスのカード](shot:library)

## 使い方
- 遊ぶ：インスタンスのカードの **プレイ** を押すか、選んで Enter。
- 開く：カード自体を押すと詳細が開きます。
- ピン留め：カードの「⋯」で **ピン留め** を選ぶと常に先頭に並びます。
- 検索：上の検索欄に名前やバージョンを入力（Ctrl+F）。
- 新規：**新規** を押します（Ctrl+N）。

## うまくいかないとき
- 以前のゲームが見つからない：[設定 › ストレージ](jay:settings#GameDirectory) でゲームフォルダーを確認してください。

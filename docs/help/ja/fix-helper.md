# 直すのを手伝って…

たくさんの MOD のどれかがクラッシュの原因のとき、**直すのを手伝って…** は半分ずつ調べます。MOD の半分をオフにし、あなたがゲームを試し、範囲を絞っていきます。

## 使い方
- 「前回」パネルで **まだ直りませんか？ › 直すのを手伝って…** を選びます。
- Jay が一部の MOD を一時的にオフにします。ゲームを起動して少し遊び、**まだクラッシュする** か **直った** を選びます。
- カードには何回目か、あと何回くらいかが出ます。途中でインスタンスを切り替えても、Jay を再起動しても続きから進みます。
- 見つかったら **X をオフにする** でその MOD だけをオフにし、ほかはすべてオンに戻ります。

## うまくいかないとき
- **すべて元に戻す** でいつでも全部の MOD を元どおりにできます。
- オンの MOD が 2 つ未満：分けようがありません。[ログ](help:logs)を見てください。

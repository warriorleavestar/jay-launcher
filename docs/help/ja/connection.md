# 接続の問題と中継サーバー

友だちにつながらないとき、1 回のチェックで理由と次に試すことがわかります。

## 使い方
- マルチプレイ下の **接続がうまくいかない？** を押すか、Ctrl+Shift+D を押します。
- **ネットワークを診断** は数秒で終わり、まずひとことで結論を出します。技術的な詳細は折りたたまれています。
- 提案に従って試します。たとえば **別の中継サーバーにする**。
- 中継サーバーは **マルチプレイ設定 › 中継サーバー** にあります。招待には必要で、直接接続には要りません。友だちと同じ中継サーバーを使うとつながりやすくなります。

## うまくいかないとき
- それでもだめなら：同じ引き出しから診断情報を書き出し、手伝ってくれる人に送ってください。

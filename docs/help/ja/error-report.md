# エラーレポートを書き出す

エラーレポートは、手伝ってくれる人がクラッシュを理解するのに必要なものを 1 つにまとめたファイルです。共有する前に中身を確認できます。

## 使い方
- インスタンスのログタブを開き、**エラーレポートを書き出す…** を押します。
- プレビューに中身が出ます：ゲームと MOD の一覧、ログの最後の 2000 行、システムと Java のバージョン。
- プレイヤー名以外のアカウント情報、トークン、コンピューターのユーザー名、ファイルパス中のユーザー名は取り除いてあります。
- **ファイルに書き出す…** か **クリップボードにコピー**。Jay が勝手にどこかへ送ることはありません。

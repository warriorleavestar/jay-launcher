# サーバー

サーバータブでは、友だちが運営する Jay サーバーに参加したり、自分で Minecraft サーバーを開いたりできます。

## 使い方
- Jay サーバーに参加：サーバー招待（JAYS2- で始まる）をマルチプレイ上部の欄に貼り付けると、サーバーへ運びます。
- 自分で開く：**アドレス › サーバーを準備 › 起動 › 招待** の順に進みます。Jay は公式の配布元からサーバーをダウンロードして確認し、必要なら Java も入れます。
- 動いている間はコンソールにコマンドを入力できます。Enter で送信、↑ ↓ で前のコマンドを呼び出します。

## うまくいかないとき
- 友だちがつながらない：最初の手順で入力したポートを、ルーターやファイアウォールで許可する必要があります。

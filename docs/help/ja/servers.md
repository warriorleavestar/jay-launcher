# サーバー

常時オンラインのサーバーには 2 つの使い方があります。フレンドが運営するサーバーに参加するか、自分で Minecraft サーバーを開きます。

## 使い方
- サーバーに参加：サーバー招待（JAYS2- で始まる）をマルチプレイの一番上の欄に貼り、**参加して保存** を押します。暗号化された招待は合言葉も入力します。保存したサーバーは「遊ぶ場所」の **サーバー** にあり、次からは **プレイ** を押します。
- 自分で開く：「ルームを開く」カードの下の **常時オンラインのサーバーを開く…** を押し、**アドレス › サーバーを準備 › 起動 › 招待** の順に進みます。Jay は公式の配布元からサーバーをダウンロードして確認し、必要なら Java も入れます。
- 動いている間はコンソールにコマンドを入力できます。Enter で送信、↑ ↓ で前のコマンドを呼び出します。

## うまくいかないとき
- フレンドがつながらない：最初の手順で入力したポートを、ルーターやファイアウォールで許可する必要があります。

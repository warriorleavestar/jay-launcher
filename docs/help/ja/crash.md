# ゲームがクラッシュした

クラッシュすると、インスタンスのページに「前回」パネルが出て、いちばんありそうな原因と、その場で直せるボタンが並びます。

## 使い方
- インスタンスを開きます。パネルには **可能性が高い**、ときには **ほかの可能性**、そしてログの根拠が出ます。
- 原因の下のボタンを押します：**メモリを増やす**、MOD を **無効化**、**シェーダーをオフにする**、**Java を選ぶ…**、**ゲームファイルを修復**。それからもう一度起動します。
- **まだ直りませんか？** から[直すのを手伝って…](help:fix-helper)やログに進めます。

## うまくいかないとき
- 既知の原因が見つからない：[エラーレポートを書き出し](help:error-report)、詳しい人に送ってください。

# 最近削除したもの

Jay で削除した MOD、パック、ワールド、インスタンスはすぐには消えません。「最近削除したもの」にしばらく残るので、取り戻せます。

## 使い方
- **設定** を開き、「最近削除したもの」を探します。それぞれ、何か、どのインスタンスのものか、残り何日かが出ます。
- **元に戻す** で元の場所に戻ります。
- **保存期間** で何日残すかを決めます。
- **完全に削除** と **空にする…** は元に戻せないので、もう一度確認します。

## うまくいかないとき
- 同じ名前のものがあって戻せない：先にそれの名前を変えるか移動してください。
- 削除したインスタンスにあった MOD：先にそのインスタンスを戻してください。

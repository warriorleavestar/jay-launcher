# ワールドのバックアップと復元

バックアップはワールドのコピーで、あとでその時点に戻せます。大きな変更の前などに取っておきましょう。

## 使い方
- インスタンスを開き、**ワールド** を選びます。ワールドを選んで B を押すか、**バックアップ** を押します。アクティビティセンターで進みます。
- ワールドの上で Enter を押すとパネルが開き、バックアップが新しい順に並びます。
- **復元…** は選んだバックアップを示してもう一度確認します。今のワールドを先にバックアップするので、何も失われません。

## うまくいかないとき
- ゲームの実行中はワールドを復元できません。先にゲームを閉じてください。

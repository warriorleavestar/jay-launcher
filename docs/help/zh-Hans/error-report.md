# 导出错误报告

错误报告是一个文件，里面是帮你的人看懂崩溃需要的东西。分享之前你先看到里面有什么。

## 怎么做
- 打开实例的“日志”页签，点【导出错误报告…】。
- 预览会写出报告里有什么：游戏和模组列表、日志最后 2000 行、系统和 Java 版本。
- Jay 已经去掉了：玩家名以外的账号信息、令牌、电脑的用户名，以及文件路径里的用户名。
- 【导出到文件…】或【复制到剪贴板】。Jay 不会自己把它发到任何地方。

# 从别的启动器搬过来

你在别的启动器里已有的实例，Jay 可以直接玩，不移动也不复制。

## 怎么做
- 在游戏库点【新建实例】，选“从其他启动器导入”。Jay 会列出找到的游戏文件夹。
- 点【用这个文件夹】；没列出来就点【选一个文件夹…】。
- Jay 在原地玩这些实例，各自独立的文件夹保留它们自己的设置。
- 第一次启动的向导也会列出找到的游戏，【加进游戏库】是一样的。

## 出问题了
- 什么都没找到：自己选文件夹（里面有 versions 的那个）。

# 整合包

整合包是一整套模组和设置，装好就是一个新实例。

## 怎么做
- 从文件：在游戏库点【新建实例】，选“整合包文件”，挑一个 .mrpack 或 CurseForge 的 .zip。安装前 Jay 先给你看里面有什么。
- 或者直接把整合包文件拖到 Jay 窗口上。
- 在线：在“发现”里选整合包类型，装一个。
- 分享你自己的：在实例页选【⋯ 更多 › 导出整合包…】，选 Modrinth（.mrpack）或 CurseForge（.zip）以及要带上的内容。

## 出问题了
- CurseForge 上有些文件不能自动下载，Jay 会列出来，让你手动下载。

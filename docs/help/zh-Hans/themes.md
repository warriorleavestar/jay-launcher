# 深浅色和界面主题包

Jay 可以跟随系统，也可以一直用浅色或深色。界面主题包能换颜色、字体和圆角。

![设置 › 外观](shot:appearance)

## 怎么做
- 最快：点侧栏底部的头像，在菜单里点“深色”或“浅色”；语言也在这个菜单里换。
- 【设置 › 外观 › 主题】：跟随系统、浅色或深色。
- 主题包：导入 .jaytheme 文件，或者把它拖到窗口上，马上生效。
- 用自己的图做主题：【设置 › 外观 › 用图片做主题…】，给背景、侧栏、立绘、横幅各选一张图（或把图拖进窗口），Jay 从图里取颜色，右边能预览。点【用上】马上换上，点【存成 .jaytheme 分享】可以发给朋友。立绘在页面后面，不挡按钮，窗口窄时自动收起。
- 内置两个：【Jay 经典琥珀】和【高对比】，删不掉。
- 旧格式的主题包读的时候会自动升级，主题卡上有标记，【复制给作者看】会复制改了什么。
- 【设置 › 外观 › 立体效果】：卡片跟着指针微微倾斜，新页面从后面浮上来；主题包可以带一个分层的场景，跟着指针移动。打开“减少动画”时这些都会关掉，安全提示始终不动。
- 主题包改不了安全提示和隐私文字。

## 出问题了
- 主题包让 Jay 打不开了：下次启动 Jay 会自己用默认外观。也可以用 --default-theme 启动 Jay。

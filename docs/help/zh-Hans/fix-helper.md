# 帮我修…

崩溃来自很多模组里的某一个时，【帮我修…】一半一半地找：先关掉一半模组，你开游戏试试，它再缩小范围。

## 怎么做
- 在“上一局”面板选【还是不行？ › 帮我修…】。
- Jay 暂时关掉一部分模组。开始游戏玩一会儿，然后选【还会崩】或【不崩了】。
- 卡片写着第几轮、大概还要几轮。中途换实例或重启 Jay 都没关系，会接着来。
- 找到后，【关掉 X】只关这一个，其他模组全部打开。

## 出问题了
- 【全部恢复原样】随时把所有模组恢复成原来的样子。
- 开着的模组不到两个：没法再分了，去看[日志](help:logs)。

# 新建实例

新建一套游戏：选版本，需要模组的话再选一个加载器。

## 怎么做
- 选版本：默认是最新的正式版。上面的芯片可以切换快照和旧版本。
- 选加载器：Fabric、Forge、NeoForge、Quilt。这个版本不支持的会变灰，并写明原因。
- **Jay 加载器**：Jay 自己的加载器，排在最后。它建在这个版本的 NeoForge 或 Forge 之上，一个实例里能混装 Fabric、Forge 和 NeoForge 的模组（实验）。名字默认是“1.21.1-Jay”这样。它还不支持的版本会变灰，并写出它支持哪些。
- 选了 Fabric、Forge 这些普通加载器时，下面有一个勾选“用通用加载器混装别的生态的模组”，只在支持的版本上能勾。以后也可以在实例的“设置”页签里打开或关掉。
- 起名字：名字不能和已有的实例重复。
- 点【安装】。也可以导入整合包文件，或者把别的启动器的游戏文件夹加进来。
- Esc 关闭面板。

## 出问题了
- 安装失败：多数是网络问题，到 [设置 › 下载线路](jay:settings#Source) 换一条线路再试。

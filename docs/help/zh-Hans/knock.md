# 敲门和安全码

有人拿邀请进你的房间时，会先敲门。谁能进由你决定。

![演练模式：练习处理敲门](shot:drill)

## 怎么做
- 敲门会弹出一张锁定的卡片，写着对方的名字和安全码。默认焦点在【拒绝】，按 Enter 不会误放人进来。
- 请朋友念出 TA 屏幕上的安全码。一模一样才让进。
- Alt+Y 让进，Alt+N 拒绝。敲门也会出现在请求条和置顶小窗里，在哪里处理都一样。
- 【房间设置】里可以设敲门等多久：2 分钟、10 分钟或一直等。

## 出问题了
- 差了一个字符：拒绝，请朋友重新敲门。中间可能有人。
- 想练一练：联机页底部的【演练一遍 ›】会演一次安全码对不上的敲门。

# 东西搬到哪了

Jay 的新布局只有三个地方：游戏库、发现、联机。下面是旧页面去了哪里。

## 旧页面 → 新位置
- **启动** → 游戏库：每个实例上的大开始按钮。
- **下载** → 游戏库里的【新建实例】；模组和整合包在“发现”。
- **资源** → 发现。
- **实例** → 游戏库，点一个实例就打开。
- **日志** → 每个实例的“日志”页签。
- **工具箱** → 设置 › 工具。
- Ctrl+K 什么都能找，旧页面名也行。

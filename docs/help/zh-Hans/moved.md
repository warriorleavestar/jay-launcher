# 东西搬到哪了

Jay 的布局有四个地方：游戏库、发现、联机、朋友。下面是旧页面去了哪里。

## 旧页面 → 新位置
- **启动** → 游戏库：每个实例上的大开始按钮。
- **下载** → 游戏库里的【新建实例】；模组和整合包在“发现”。
- **资源** → 发现。
- **实例** → 游戏库，点一个实例就打开。
- **日志** → 每个实例的“日志”页签。
- **工具箱** → 清理在 设置 › 存储，下载 Java 在 设置 › 游戏默认，检查更新在 设置 › 关于。
- **账号** → “我”：点左下角的头像。好友码和你的设备也在那里。
- **深浅色和语言**（原来在头像的菜单里）→ “我” › 外观，设置里也照旧能改。
- **朋友**（原来在联机设置里）→ 侧栏的“朋友”入口。加朋友、备份和恢复都在那里。
- **信任的人**（原来是联机设置里的一张名单）→ 朋友页里每个人身上的“TA 敲门直接进”开关。
- **联机设置**（原来是联机页的一个页签）→ 设置 › 联机（邀请、新房间默认、联机组件、紧急断开）和 设置 › 网络（公共网络、中转、STUN）。这台电脑的安全码和设备码 → “我” › 我的设备。检测网络、调试模式、诊断报告 → “连接有问题？”。
- Jay 正在用哪个网络 → 右上角的网络状态，每一页都有。
- Ctrl+K 什么都能找，旧页面名也行。

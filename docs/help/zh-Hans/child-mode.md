# 给孩子用（给家长）

打开“给孩子用”后，Jay 的联机会更保守，适合孩子自己玩。

## 怎么做
- 打开 [设置 › 隐私与安全 › 给孩子用](jay:settings#ChildMode)，勾上总开关；下面六项会一起打开，也可以单独调。
- 关掉远程协助：别人不能请求看或控制这台电脑。
- 不用公开房间和公共网络：只能用邀请和朋友联机。
- 不允许“经我 / 经 TA”的网络：不能借别人的电脑上网。
- 只接收朋友发的文件：其他人发来的文件会直接拒绝。
- 有人敲门总要我同意：朋友也要同意才能进。
- 通知里不显示名字和内容。

## 要知道的
- 没有家长密码：会改设置文件的孩子挡不住，反而给人错误的安全感。设置页写着“上次改动”的时间，你能看出有没有被改过。
- 遇到陌生人敲门、发文件、要远程协助时，教孩子点【拒绝】并告诉你。

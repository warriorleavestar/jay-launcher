# 模组

实例的“模组”页签列出它里面的每个模组。可以搜索、不删除只关掉，也可以更新。

## 怎么做
- 打开实例，选“模组”页签（Alt+2）。
- 在搜索框里输入，或者用芯片：【全部】【已关】【有更新】【有问题】。
- 点一个模组，右边显示它的详情。
- 勾选几个模组会出现批量栏：一起关掉、打开或删除。做完马上有【撤销】。
- 【添加模组 › 在线找…】打开“发现”，只显示适合这个实例的模组。也可以把 .jar 文件拖到窗口上。
- Jay 查到更新后会出现【全部更新】。

## 出问题了
- 删掉的模组在[最近删除](help:recycle)里放几天。
- 加了模组后游戏崩溃：看[帮我修…](help:fix-helper)。

# 最近删除

在 Jay 里删掉的模组、资源包、世界和实例不会马上消失，会先放在“最近删除”里，可以找回来。

## 怎么做
- 打开【设置】，找到“最近删除”。每一项写着是什么、来自哪个实例、还剩几天。
- 【恢复】放回原来的位置。
- 【保留】设东西放多少天。
- 【永久删除】和【清空…】会再确认一次，因为删了就找不回来了。

## 出问题了
- 恢复不了，因为原位置有同名的东西：先改名或移走它。
- 来自已删除实例的模组：先恢复那个实例。

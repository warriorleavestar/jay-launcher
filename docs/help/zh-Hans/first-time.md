# 第一次用 Jay

Jay 是一个 Minecraft Java 版启动器。第一次打开时有一个两步的向导：先选语言、加一个账号，再选从哪里开始玩。

## 怎么做
- 第 1 步：在右上角换语言；填一个名字加离线账号，或者点【用微软账号登录】。
- 第 2 步：默认装最新的原版，点【安装并开始】。也可以点“选别的版本”。
- 向导随时可以点【跳过】，之后在 [游戏库](jay:library) 里点【新建实例】一样能装。

## 出问题了
- 名字不能用：只能用英文字母、数字和下划线，3 到 16 个字。
- 安装很慢：到 [设置 › 下载源](jay:settings#Source) 换一个下载源。

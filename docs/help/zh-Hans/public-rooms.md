# 公开房间

公开房间来自社区或朋友运行的公共网络。现在还没有能直接用的公共网络，要先添加一个。

## 怎么做
- 在联机大厅的“去哪玩”里点【公开】。还没添加公共网络时，点【添加公共网络…】，贴上别人给你的地址。
- 连接。第一次连接前，Jay 会先说明别人能看到什么，然后才发送任何东西。
- 按 / 搜索，按版本筛选，给列表排序。F5 刷新。
- 想列出自己的房间：连上公共网络后，开房间时“谁能进”选【公开（可加密码）】。已经开着的房间，在房间里点【在公开房间里列出 ›】。
- 有设备码？先连上朋友用的那个公共网络，再用设备码找 TA 的房间。

## 出问题了
- 给孩子用时可以关掉公开房间：看[给孩子用](help:child-mode)。

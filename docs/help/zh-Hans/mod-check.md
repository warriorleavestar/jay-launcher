# 进房间前对一下模组

加入带模组的房间时，Jay 会拿你的模组和房主的比一比，免得一进去就崩。

## 怎么做
- 敲门后，“对一下模组”卡片会比对两边的列表。比对完之前 Jay 不会说“一样”。
- 它写出你缺哪些、哪些版本不同、你多了哪些。只在你这边运行的模组（比如小地图）多了通常没关系。
- 【一键同步】解决：同步到一个新实例（你的实例不动），或者直接改你的实例（被换掉的文件进最近删除）。Modrinth 上有的从那里下，其余由房主经房间加密发给你。
- 【不管了，直接进】照样进去。要是崩了，“上一局”面板会记着这件事。

## 出问题了
- 房主关掉了模组同步：请房主把整合包发给你。

# 工具箱

工具箱里是不常用但有时很有用的东西：检查 Jay 更新、修复游戏文件、清理缓存等。

## 怎么做
- 从 [设置 › 工具](jay:settings#OpenTools) 打开，或者在设置页上面点“工具箱”页签。
- 每个工具都写着它会做什么；会删东西的操作会先让你确认。

## 出问题了
- 检查更新没有反应：需要先在 [设置 › 下载与服务](jay:settings#UpdateFeed) 填更新地址；不填 Jay 不会为此联网。

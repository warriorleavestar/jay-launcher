# Jay 不收集数据：联网清单

Jay 没有遥测、统计、广告，也没有远程开关。它只在 5 种情况下联网，“关于和隐私”页上写着每一种现在的状态。

## 5 种情况
- 你点的下载：游戏、模组、Java、整合包、加载器、联机组件。
- 微软登录：登录和刷新登录、你自己的皮肤。
- Modrinth / CurseForge：只在你打开“发现”或点“检查更新”时。
- 检查 Jay 更新：每天一次（可以关掉）和你点“检查更新”时，向 Jay 官方发布页或你填的更新地址查最新版本；只提示，不下载。
- 联机：开房间、加入、公开房间、加入服务器。

## 怎么做
- 打开 [关于和隐私](jay:about)：每一项后面有“改 ›”，点了直接去对应的设置。
- 存在你电脑上的东西都在数据文件夹里，页上有【打开数据文件夹】。

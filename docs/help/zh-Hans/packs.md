# 资源包和光影

资源包改材质和声音，光影改光照。Jay 用的资源包列表和游戏里“资源包”界面是同一份。

## 怎么做
- 打开实例，选“资源包”。分【已启用】【未启用】两栏，越靠上越优先。
- 空格打开或关掉选中的包，Alt+↑ / Alt+↓ 移动它。
- 标签会写出这个包是给旧版本还是新版本做的。可能照样能用，只是有些材质看起来不对。
- 光影需要 Iris 模组。没装时“光影”页签会有横幅和【装 Iris】。
- 选一个光影就用它，或者选【不用光影】。

## 出问题了
- 开着光影游戏崩溃：“上一局”面板可以让下次启动不开光影，光影包还留着。
- 删掉的包在[最近删除](help:recycle)里。

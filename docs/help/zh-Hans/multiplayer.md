# 联机

和朋友一起玩：开一个房间，把邀请发给朋友；朋友贴上邀请敲门，你同意后就能进来。

![联机大厅：最上面是加入，下面是开房间和去哪玩](shot:multiplayer-lobby)

联机页没有页签：没在房间里时是大厅，进了房间就是房间。

## 怎么做
- 加入：把朋友给的码贴进最上面的框，点按钮，等对方同意。房间邀请、服务器邀请、好友码、网络地址都贴这一个框，按钮上写着它要做什么。
- 开房间：点【开房间】就行，四样选择不改也能开。谁能进（只有我邀请的人、我的朋友可以直接敲门、公开）；怎么连（自动、只走中转、不经服务器）；保护（标准、加强、最高）；范围（只联这个游戏、整个局域网）。灰掉的选项下面写着原因。
- 只走中转：全部经中转，Jay 不让房间里的人互相直连，正常使用时互相看不到 IP；用改过的程序的人仍可能查到。会慢一点。朋友的 Jay 太旧、不认这个设置时进不来，要先更新。
- 不经服务器：按钮变成【生成加密直连码】。码发给朋友，口令用别的方式告诉 TA。两台电脑直接相连，连不上时也不会改走中转。为了查出你的地址，Jay 会问设置 › 网络里列的 STUN 服务器，它们能看到你的 IP。
- 去哪玩：朋友邀请你的房间、公开房间和你存下的服务器在一个列表里，用【全部 / 朋友 / 公开 / 服务器】筛选。
- 有人敲门：房间里会出现一张卡片，点【同意】或【拒绝】（Alt+Y / Alt+N）。
- 安全码：两边看到的安全码一样，说明没有人在中间冒充。
- 第一次联机要装一个联机组件：按钮会先写“先装联机组件”，点一下装好，再点一下就开房间或加入。

## 在房间里
- 顶上是房间名、人数和连接标记（“直连 · 18 ms”或“经中转 · 82 ms”）。每个人的头像下面有一条细线：直连和经中转各一种。核对过的朋友头像上有对勾。
- 【邀请】：选有效期（10 分钟、1 天、30 天）和可用次数（1 次、不限），点【生成邀请】。邀请是一张小卡片，可以【复制】或【发给朋友】，点【显示】才看到码。不限次数的邀请每次敲门都先问你。30 天的邀请在你以后开的每个房间都能用（现在开着的这个房间里没有别的邀请时，它马上也能用，卡片上会写），可以随时作废。
- 点连接标记看“谁能看到什么”：一张固定的表，写谁能看到你的 IP、谁能看到内容。现在适用的那一行标着“现在”。下面有个开关“只走中转”：打开后 Jay 会请其他人不直连你，正常使用时别人看不到你的 IP（用改过的程序的人仍可能查到），延迟会高一些；切换时会重新连一下房间。没开的时候，就算这会儿经中转，Jay 也会接着试直连，所以房间里的人能查到你的 IP。想让每个房间都这样，在 设置 › 联机 里打开“默认只走中转”。
- 点一个人：看 TA 的安全码、是不是朋友、怎么连的。“和 TA 共享”里有远程协助、帮 TA 转发游戏、让 TA 经我上网，每一样打开前都会先问你。
- 【进入游戏】：加入的人点它，用选好的实例直接进朋友的世界。

## 出问题了
- 连不上：打开“检测网络”，它会告诉你卡在哪一步。
- 给孩子用：可以关掉远程协助、公共网络等，见 [给孩子用](help:child-mode)。

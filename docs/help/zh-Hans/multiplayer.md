# 联机

和朋友一起玩：开一个房间，把邀请发给朋友；朋友贴上邀请敲门，你同意后就能进来。

![联机大厅：最上面是加入，下面是开房间和去哪玩](shot:multiplayer-lobby)

联机页没有页签：没在房间里时是大厅，进了房间就是房间。

## 怎么做
- 加入：把朋友给的码贴进最上面的框，点按钮，等对方同意。房间邀请、服务器邀请、好友码、网络地址都贴这一个框，按钮上写着它要做什么。
- 开房间：点【开房间】就行，四样选择不改也能开。谁能进（只有我邀请的人、我的朋友可以直接敲门、公开）；怎么连（自动、只走中转、不经服务器）；保护（标准、加强、最高）；范围（只联这个游戏、整个局域网）。灰掉的选项下面写着原因。
- 只走中转：房间里的人互相看不到 IP，会慢一点。
- 不经服务器：按钮变成【生成加密直连码】。码发给朋友，口令用别的方式告诉 TA。
- 去哪玩：朋友邀请你的房间、公开房间和你存下的服务器在一个列表里，用【全部 / 朋友 / 公开 / 服务器】筛选。
- 有人敲门：房间里会出现一张卡片，点【同意】或【拒绝】（Alt+Y / Alt+N）。
- 安全码：两边看到的安全码一样，说明没有人在中间冒充。
- 第一次联机要装一个联机组件：按钮会先写“先装联机组件”，点一下装好，再点一下就开房间或加入。

## 出问题了
- 连不上：打开“检测网络”，它会告诉你卡在哪一步。
- 给孩子用：可以关掉远程协助、公共网络等，见 [给孩子用](help:child-mode)。

# 联机

和朋友一起玩：开一个房间，把邀请码发给朋友；朋友贴上邀请码敲门，你同意后就能进来。

## 怎么做
- 开房间：在“联机”页点【开房间】，选要开的实例，然后点【邀请朋友】（Ctrl+Shift+I）。
- 加入：把朋友给的邀请码贴进输入框，点【敲门】，等对方同意。
- 有人敲门：房间里会出现一张卡片，点【同意】或【拒绝】（Alt+Y / Alt+N）。
- 安全码：两边看到的安全码一样，说明没有人在中间冒充。

## 出问题了
- 连不上：打开“检测网络”，它会告诉你卡在哪一步。
- 给孩子用：可以关掉远程控制、公共网络等，见 [给孩子用](help:child-mode)。

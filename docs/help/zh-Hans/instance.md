# 实例详情

一个实例就是一套独立的游戏：自己的版本、加载器、模组、存档和设置，互不影响。

## 怎么做
- 开始：点右上角琥珀色的【开始】。
- 页签：概览、模组、世界、资源包、光影、服务器、截图、日志、设置。用 Alt+数字 切换，或者 Ctrl+Tab。
- 加模组：在“模组”页签点【＋ 添加模组】，会带你去“发现”并只显示适合这个实例的模组。
- 上一局崩溃了：概览上会有“上一局”面板，直接点里面的修复按钮（调内存、禁用模组、关光影）。

## 出问题了
- 进不去游戏：打开“日志”页签，按 F8 跳到第一条错误；或者在“上一局”面板里点【帮我修…】。

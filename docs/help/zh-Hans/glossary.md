# Jay 里的词

Jay 用到的词，一句白话解释。

## 词
- **实例**：一套游戏，有自己的版本、模组和世界。
- **加载器**：让模组能运行的东西，比如 Fabric、Forge、NeoForge、Quilt。
- **房间**：你的世界，加上一条只有你邀请的朋友能进的通道。
- **邀请码**：发给朋友的码，TA 用它来敲你房间的门。
- **安全码**：两边都能看到的码。一样就说明中间没有别人。
- **好友码**：在公开房间里找到朋友的房间。
- **中转服务器**：两台电脑直接连不上时，帮它们接上的服务器。
- **直接连上 / 经中转**：你们的游戏是直接互通，还是经过中转服务器。

# Jay 里的词

Jay 用到的词，一句白话解释。

## 词
- **实例**：一套游戏，有自己的版本、模组和世界。
- **加载器**：让模组能运行的东西，比如 Fabric、Forge、NeoForge、Quilt。
- **房间**：你的世界，加上一条只有你邀请的朋友能进的通道。
- **邀请**：发给朋友的一串码，TA 用它来敲你房间的门。里面没有你的地址。
- **安全码**：两边都能看到的码。一样就说明中间没有别人。
- **设备码**：指向你这台电脑的码，朋友用它在公开房间里找到你的房间。
- **好友码**：让别人申请加你为朋友的码。它不是设备码，找不到你的房间。
- **中转**：两台电脑直接连不上时，帮它们转交数据的服务器。它看得到你的 IP，看不到内容。
- **直接连上 / 经中转**：你们的游戏是直接互通，还是经过中转。

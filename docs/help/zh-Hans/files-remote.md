# 传文件和远程协助

在房间里可以给某人发文件，或者请求控制对方的电脑帮 TA 弄。两样都必须对方同意。

## 怎么做
- 发文件：选一个人，在私聊里发。对方会看到一张锁定的卡片，由 TA 决定。
- 收到的文件只存到“下载/Jay”。Jay 从不自己打开它，是程序文件时会提醒你。
- 远程协助：在房间里点一个人，在“和 TA 共享”里点【请求看 TA 的屏幕…】。每次都要对方同意。进行中对方屏幕有红框，按 Ctrl+Shift+F12 马上停。

## 出问题了
- 远程协助只给信任的人。Jay 的人永远不会找你要。
- 给孩子用时可以关掉远程协助：看[给孩子用](help:child-mode)。

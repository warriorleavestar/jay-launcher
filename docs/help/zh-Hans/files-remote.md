# 传文件和远程协助

可以给朋友或房间里的人发文件：一个文件、一个世界、一份模组列表、一张截图、一份日志或一个文件夹。每次都要对方点接收。也可以请求控制对方的电脑帮 TA 弄，同样要对方同意。

## 发文件
- 在朋友的对话里点输入框左边的回形针，选要发什么；或者把文件直接拖到对话上。
- 在房间里点一个人，点【发文件】。在实例的“世界”页签里，每个世界那一行有【发给朋友】。
- 世界和文件夹会先打包成一个压缩包，游戏里的存档不变。模组列表只发名字和版本，不发模组本身。日志发出去之前会先打码（电脑用户名、令牌、邮箱）。
- 对话里有一张卡片，写着进度、直连还是经中转、速度。可以【取消】。
- 朋友不在同一个房间时，文件先在这台电脑上排着，你们在同一个房间时自动开始。中途断了的，再见面时从断开的地方接着发。

## 收文件
- 有人发来时，顶上的请求条里写着是谁、是不是核对过的朋友、什么类型。默认是【拒绝】，Alt+Y 接收，Alt+N 拒绝。五分钟不理算没接收。
- 收到的文件只存到“下载/Jay”（可以在 [设置 › 联机 › 文件](jay:settings#FilesFolder) 里换）。Jay 从不自己打开它，是程序文件时会提醒你。
- 收到世界：卡片上有【导入到实例】。收到模组列表：【对一下模组】，写出缺几个、版本不同几个。

## 远程协助
- 在房间里点一个人，在“和 TA 共享”里请求看 TA 的屏幕。每次都要对方同意。进行中对方屏幕有红框，按 Ctrl+Shift+F12 马上停。

## 值得知道
- 文件端到端加密，房主和中转看不到内容。
- 设置 › 联机 › 文件里可以打开“核对过的朋友发来的直接收下”（默认关；程序文件还是要问），也可以限速。
- 远程协助只给信任的人。Jay 的人永远不会找你要。给孩子用时只收朋友发来的文件，也可以关掉远程协助：看[给孩子用](help:child-mode)。

# 服务器

一直在线的服务器有两种用法：加入朋友运行的服务器，或者自己开一个 Minecraft 服务器。

## 怎么做
- 加入服务器：把服务器邀请（以 JAYS2- 开头）贴到联机页最上面的框里，点【加入并存下】。加密的邀请还要填口令。存下的服务器在“去哪玩”的【服务器】里，以后点【进服】。
- 自己开：在开房间卡片下面点【开一个一直在线的服务器…】，按步骤走【地址 › 准备服务端 › 启动 › 邀请】。Jay 从官方来源下载服务端并校验，需要时顺便下载 Java。
- 运行时可以在控制台输入命令。Enter 发送，↑ ↓ 调出之前的命令。

## 出问题了
- 朋友连不上你的服务器：路由器或防火墙要放行第一步填的端口。

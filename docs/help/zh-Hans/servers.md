# 服务器

“服务器”页签用来加入朋友运行的 Jay 服务器，或者自己开一个 Minecraft 服务器。

## 怎么做
- 加入 Jay 服务器：把服务器邀请（以 JAYS1- 开头）贴到联机页顶部的框里，Jay 会把它带到“服务器”。
- 自己开：按步骤走【地址 › 准备服务端 › 启动 › 邀请】。Jay 从官方来源下载服务端并校验，需要时顺便下载 Java。
- 运行时可以在控制台输入命令。Enter 发送，↑ ↓ 调出之前的命令。

## 出问题了
- 朋友连不上你的服务器：路由器或防火墙要放行第一步填的端口。

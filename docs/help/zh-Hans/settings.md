# 设置

设置分成 10 组：常规、外观、游戏默认、下载与服务、存储、隐私与安全、联机、工具、实验、关于。

## 怎么做
- 宽窗口在左边选分组；窄一点时分组变成上面的下拉；最窄时先列出分组，点进去再改。
- 搜索：按 Ctrl+F，输入设置的名字（中文可以用拼音首字母），Enter 跳过去。
- 也可以在任何地方按 Ctrl+K，输入 # 加设置名。
- 改动会马上保存，不用点保存。

## 出问题了
- 找不到某个设置：用 Ctrl+F 搜一下，结果会写成“分组 › 设置”。

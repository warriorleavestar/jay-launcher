# 游戏崩溃了

游戏崩溃后，实例页会有“上一局”面板，写出最可能的原因，并给出当场就能修的按钮。

## 怎么做
- 打开实例。面板里写着【很可能】，有时还有【也可能】，以及日志里的证据。
- 点原因下面的按钮：【调高内存】、【禁用】某个模组、【关掉光影】、【选一个 Java…】或【修复游戏文件】，然后再开始游戏。
- 【还是不行？】里有[帮我修…](help:fix-helper)和日志。

## 出问题了
- 没找到已知原因：[导出错误报告](help:error-report)，发给懂的人看。

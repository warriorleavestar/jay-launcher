# 朋友

朋友是你核对过一次的人。之后互相邀请，不用再经聊天软件传码。左边是人，右边是和 TA 的对话。

## 怎么做
- 加朋友：点【加朋友】。把你的**好友码**发给对方，或者贴上对方的。对方接受后，两人打电话或当面对四个表情，一样就点【一样，加为朋友】。加朋友只有这一种方式。
- 看一位朋友：点 TA。名字下面写着现在知道的情况：已核对、和你在同一个房间、在 TA 的哪个房间里，或者有新设备待确认。
- 安全码和设备：点对话顶上的“端到端加密 · 已核对”。在那里能移除 TA 的某台设备，或者【从朋友里移除】。
- 邀请：先开一个房间，再点【邀请到我的房间】。对话里会记一行，后面写已寄出、已送达，或者还没送到。
- 进 TA 的房间：TA 邀请你以后，这里会出现【加入“房间名”】。
- 发消息：现在只有两人在同一个房间里时才能发。不在一起时输入框是灰的，下面写着原因。
- 发文件：点输入框左边的回形针，或者把文件拖到对话上。不在同一个房间时文件先在你电脑上排着，碰面后自动发出。见[传文件和远程协助](help:files-remote)。
- **TA 敲门直接进**：打开后，TA 拿着你任何一张还有效的邀请敲门，不用先问你。原来的“信任的人”名单就是这个开关。
- 备份和恢复朋友列表：右上角的【⋯】。备份用你的 Jay 账户锁着。

## 值得知道
- “见过的人”是进过你的房间、但没对过表情的人。可以【加为朋友】，也可以只打开“TA 敲门直接进”。房间关了以后，只有打开了开关的人还留在这里。
- 朋友有了新设备时，要你点【是 TA】确认。确认之前，那台设备敲门照样会问你。
- 好友码只能让别人请求加你。它不是邀请，里面也没有你的地址。
- 给朋友的邀请加密后经公共网络送达。顶上那一行写着经哪个网络；没连的话，点旁边的【连接网络】。
- 对话只留在这次运行里，不写到硬盘上。关掉 Jay 就没有了。
- 双方都有 Jay 账户时，朋友换了新电脑会自动加上，并给你一条提示。没有的话，每台电脑要分别添加。
- 打开“给孩子用”后公共网络是关的，所以这一页只留一句说明，每次敲门也都会问你。

# 快捷键

所有操作都能用鼠标点，下面是对应的快捷键。

## 全局
- Ctrl+K：命令面板（搜实例、设置、页面）。
- Ctrl+1 / Ctrl+2 / Ctrl+3：游戏库 / 发现 / 联机。
- Ctrl+,：设置。
- Ctrl+J：活动中心。
- F1：本页帮助；Shift+F1：帮助中心。
- Alt+← / Alt+→：返回 / 前进。

## 页面里
- Ctrl+F：搜索当前页。
- Esc：关闭抽屉、面板或清空搜索。
- F8 / Shift+F8：日志里跳到下一条 / 上一条错误。

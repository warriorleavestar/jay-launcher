# 连接有问题和中转服务器

连不上朋友时，检测一次就告诉你原因和该试什么。

## 怎么做
- 点联机页底部的【连接有问题？】，或按 Ctrl+Shift+D。
- 【检测我的网络】几秒钟，先用一句白话给结论，技术细节折叠起来。
- 按建议试，比如【换中转服务器】。
- 中转服务器在【联机设置 › 中转服务器】。邀请需要中转服务器，直连不需要。和朋友用同样的中转服务器更容易连上。

## 出问题了
- 还是不行：在同一个抽屉里导出诊断信息，发给能帮你的人。

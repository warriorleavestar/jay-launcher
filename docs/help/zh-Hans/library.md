# 游戏库

游戏库是 Jay 的主页：你装过的每一套游戏（实例）都在这里，最近玩过的排在前面。

## 怎么做
- 开始游戏：点实例卡上的【开始】，或者选中后按 Enter。
- 打开实例：点卡片本身，进实例详情页。
- 固定：在卡片的“⋯”里点【固定】，它会一直排在前面。
- 搜索：在上面的搜索框里输入名字或版本号（Ctrl+F）。
- 新建：点【新建】（Ctrl+N）。

## 出问题了
- 找不到以前的游戏：到 [设置 › 存储](jay:settings#GameDirectory) 看游戏目录是不是选对了。

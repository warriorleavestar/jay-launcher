# 給孩子用（給家長）

開啟「給孩子用」後，Jay 的連線會更保守，適合孩子自己玩。

## 怎麼做
- 開啟 [設定 › 隱私與安全 › 給孩子用](jay:settings#ChildMode)，勾上總開關；下面六項會一起開啟，也可以單獨調。
- 關掉遠端協助：別人不能請求看或控制這臺電腦。
- 不用公開房間和公共網路：只能用邀請和朋友連線。
- 不允許「經我 / 經 TA」的網路：不能借別人的電腦上網。
- 只接收朋友發的檔案：其他人發來的檔案會直接拒絕。
- 有人敲門總要我同意：朋友也要同意才能進。
- 通知裡不顯示名字和內容。

## 要知道的
- 沒有家長密碼：會改設定檔案的孩子擋不住，反而給人錯誤的安全感。設定頁寫著「上次改動」的時間，你能看出有沒有被改過。
- 遇到陌生人敲門、傳檔案、要遠端協助時，教孩子點【拒絕】並告訴你。

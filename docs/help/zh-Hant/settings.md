# 設定

設定分成 10 組：常規、外觀、遊戲預設、下載與服務、儲存、隱私與安全、連線、工具、實驗、關於。

## 怎麼做
- 寬視窗在左邊選分組；窄一點時分組變成上面的下拉；最窄時先列出分組，點進去再改。
- 搜尋：按 Ctrl+F，輸入設定的名字（中文可以用拼音首字母），Enter 跳過去。
- 也可以在任何地方按 Ctrl+K，輸入 # 加設定名。
- 改動會馬上儲存，不用點儲存。

## 出問題了
- 找不到某個設定：用 Ctrl+F 搜一下，結果會寫成「分組 › 設定」。

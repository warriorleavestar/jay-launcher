# Jay 不收集資料：連網清單

Jay 沒有遙測、統計、廣告，也沒有遠端開關。它只在 5 種情況下連網，「關於和隱私」頁上寫著每一種現在的狀態。

## 5 種情況
- 你點的下載：遊戲、模組、Java、整合包、載入器、連線元件。
- 微軟登入：登入和重新整理登入、你自己的皮膚。
- Modrinth / CurseForge：只在你開啟「探索」或點「檢查更新」時。
- 檢查 Jay 更新：每天一次（可以關掉）和你點「檢查更新」時，向 Jay 官方發布頁或你填的更新位址查詢最新版本；只提示，不下載。
- 連線：開房間、加入、公開房間、加入伺服器。

## 怎麼做
- 開啟 [關於和隱私](jay:about)：每一項後面有「改 ›」，點了直接去對應的設定。
- 存在你電腦上的東西都在資料資料夾裡，頁上有【開啟資料資料夾】。

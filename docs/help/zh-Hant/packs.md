# 資源包和光影

資源包改材質和聲音，光影改光照。Jay 用的資源包列表和遊戲裡「資源包」介面是同一份。

## 怎麼做
- 開啟實例，選「資源包」。分【已啟用】【未啟用】兩欄，越靠上越優先。
- 空格開啟或關掉選中的包，Alt+↑ / Alt+↓ 移動它。
- 標籤會寫出這個包是給舊版本還是新版本做的。可能照樣能用，只是有些材質看起來不對。
- 光影需要 Iris 模組。沒裝時「光影」頁籤會有橫幅和【裝 Iris】。
- 選一個光影就用它，或者選【不用光影】。

## 出問題了
- 開著光影遊戲崩潰：「上一局」面板可以讓下次啟動不開光影，光影包還留著。
- 刪掉的包在[最近刪除](help:recycle)裡。

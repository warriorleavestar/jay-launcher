# 模組

實例的「模組」頁籤列出它裡面的每個模組。可以搜尋、不刪除只關掉，也可以更新。

## 怎麼做
- 開啟實例，選「模組」頁籤（Alt+2）。
- 在搜尋框裡輸入，或者用晶片：【全部】【已關】【有更新】【有問題】。
- 點一個模組，右邊顯示它的詳情。
- 勾選幾個模組會出現批次欄：一起關掉、開啟或刪除。做完馬上有【撤銷】。
- 【新增模組 › 線上找…】開啟「探索」，只顯示適合這個實例的模組。也可以把 .jar 檔案拖到視窗上。
- Jay 查到更新後會出現【全部更新】。

## 出問題了
- 刪掉的模組在[最近刪除](help:recycle)裡放幾天。
- 加了模組後遊戲崩潰：看[幫我修…](help:fix-helper)。

# 連線有問題和中轉

連不上朋友時，檢測一次就告訴你原因和該試什麼。

![「連線有問題？」抽屜](shot:connection)

## 怎麼做
- 點連線頁底部的【連線有問題？】，或按 Ctrl+Shift+D。
- 【檢測我的網路】幾秒鐘，先用一句白話給結論，技術細節摺疊起來。
- 按建議試，比如【換中轉】。
- 中轉在【設定 › 網路 › 中轉】。邀請需要中轉，直連不需要。和朋友用同樣的中轉更容易連上。

## 出問題了
- 還是不行：在同一個抽屜裡匯出診斷資訊，發給能幫你的人。

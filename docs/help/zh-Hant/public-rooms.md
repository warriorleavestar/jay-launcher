# 公開房間

公開房間來自社群或朋友執行的公共網路。Jay 沒有內建公共網路。

## 怎麼做
- 開啟【連線 › 公開房間】。還沒新增公共網路時，點【新增公共網路…】，貼上別人給你的地址。
- 連線。第一次連線前，Jay 會先說明別人能看到什麼，然後才傳送任何東西。
- 按 / 搜尋，按版本篩選，給列表排序。F5 重新整理。
- 想列出自己的房間：先開房間，再在房間裡點【在公開房間裡列出 ›】。
- 有好友碼？先連上朋友用的那個公共網路，再用好友碼找 TA 的房間。

## 出問題了
- 給孩子用時可以關掉公開房間：看[給孩子用](help:child-mode)。

# 最近刪除

在 Jay 裡刪掉的模組、資源包、世界和實例不會馬上消失，會先放在「最近刪除」裡，可以找回來。

## 怎麼做
- 開啟【設定】，找到「最近刪除」。每一項寫著是什麼、來自哪個實例、還剩幾天。
- 【還原】放回原來的位置。
- 【保留】設東西放多少天。
- 【永久刪除】和【清空…】會再確認一次，因為刪了就找不回來了。

## 出問題了
- 恢復不了，因為原位置有同名的東西：先改名或移走它。
- 來自已刪除實例的模組：先恢復那個實例。

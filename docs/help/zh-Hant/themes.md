# 深淺色和介面主題包

Jay 可以跟隨系統，也可以一直用淺色或深色。介面主題包能換顏色、字型和圓角。

## 怎麼做
- 【設定 › 外觀 › 佈景主題】：跟隨系統、淺色或深色。
- 主題包：匯入 .jaytheme 檔案，或者把它拖到視窗上，馬上生效。
- 內建兩個：【Jay 經典琥珀】和【高對比】，刪不掉。
- 舊格式的主題包讀的時候會自動升級，主題卡上有標記，【複製給作者看】會複製改了什麼。
- 主題包改不了安全提示和隱私文字。

## 出問題了
- 主題包讓 Jay 打不開了：下次啟動 Jay 會自己用預設外觀。也可以用 --default-theme 啟動 Jay。

# 敲門和安全碼

有人拿邀請進你的房間時，會先敲門。誰能進由你決定。

![演練模式：練習處理敲門](shot:drill)

## 怎麼做
- 敲門會彈出一張鎖定的卡片，寫著對方的名字和安全碼。預設焦點在【拒絕】，按 Enter 不會誤放人進來。
- 請朋友念出 TA 螢幕上的安全碼。一模一樣才讓進。
- Alt+Y 讓進，Alt+N 拒絕。敲門也會出現在請求條和置頂小窗裡，在哪裡處理都一樣。
- 【房間設定】裡可以設敲門等多久：2 分鐘、10 分鐘或一直等。

## 出問題了
- 差了一個字元：拒絕，請朋友重新敲門。中間可能有人。
- 想練一練：連線頁底部的【演練一遍 ›】會演一次安全碼對不上的敲門。

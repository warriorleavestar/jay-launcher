# 幫我修…

崩潰來自很多模組裡的某一個時，【幫我修…】一半一半地找：先關掉一半模組，你開遊戲試試，它再縮小範圍。

## 怎麼做
- 在「上一局」面板選【還是不行？ › 幫我修…】。
- Jay 暫時關掉一部分模組。開始遊戲玩一會兒，然後選【還會當機】或【不當機了】。
- 卡片寫著第幾輪、大概還要幾輪。中途換實例或重啟 Jay 都沒關係，會接著來。
- 找到後，【關掉 X】只關這一個，其他模組全部開啟。

## 出問題了
- 【全部恢復原狀】隨時把所有模組恢復成原來的樣子。
- 開著的模組不到兩個：沒法再分了，去看[日誌](help:logs)。

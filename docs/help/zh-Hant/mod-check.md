# 進房間前對一下模組

加入帶模組的房間時，Jay 會拿你的模組和房主的比一比，免得一進去就崩。

## 怎麼做
- 敲門後，「對一下模組」卡片會比對兩邊的列表。比對完之前 Jay 不會說「一樣」。
- 它寫出你缺哪些、哪些版本不同、你多了哪些。只在你這邊執行的模組（比如小地圖）多了通常沒關係。
- 【一鍵同步】解決：同步到一個新實例（你的實例不動），或者直接改你的實例（被換掉的檔案進最近刪除）。Modrinth 上有的從那裡下，其餘由房主經房間加密發給你。
- 【不管了，直接進】照樣進去。要是崩了，「上一局」面板會記著這件事。

## 出問題了
- 房主關掉了模組同步：請房主把整合包發給你。

# 匯出錯誤報告

錯誤報告是一個檔案，裡面是幫你的人看懂崩潰需要的東西。分享之前你先看到裡面有什麼。

## 怎麼做
- 開啟實例的「日誌」頁籤，點【匯出錯誤報告…】。
- 預覽會寫出報告裡有什麼：遊戲和模組列表、日誌最後 2000 行、系統和 Java 版本。
- Jay 已經去掉了：玩家名以外的帳號資訊、令牌、電腦的使用者名稱，以及檔案路徑裡的使用者名稱。
- 【匯出到檔案…】或【複製到剪貼簿】。Jay 不會自己把它發到任何地方。

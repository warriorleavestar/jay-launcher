# 傳檔案和遠端協助

可以給朋友或房間裡的人發檔案：一個檔案、一個世界、一份模組清單、一張截圖、一份日誌或一個資料夾。每次都要對方點接收。也可以請求控制對方的電腦幫 TA 弄，同樣要對方同意。

## 發檔案
- 在朋友的對話裡點輸入框左邊的迴紋針，選要發什麼；或者把檔案直接拖到對話上。
- 在房間裡點一個人，點【傳檔案】。在實例的「世界」頁籤裡，每個世界那一行有【傳給朋友】。
- 世界和資料夾會先打包成一個壓縮檔，遊戲裡的存檔不變。模組清單只發名字和版本，不發模組本身。日誌發出去之前會先打碼（電腦使用者名稱、權杖、信箱）。
- 對話裡有一張卡片，寫著進度、直連還是經中轉、速度。可以【取消】。
- 朋友不在同一個房間時，檔案先在這台電腦上排著，你們在同一個房間時自動開始。中途斷了的，再見面時從斷開的地方接著發。

## 收檔案
- 有人發來時，頂上的請求列裡寫著是誰、是不是核對過的朋友、什麼類型。預設是【拒絕】，Alt+Y 接收，Alt+N 拒絕。五分鐘不理算沒接收。
- 收到的檔案只存到「下載/Jay」（可以在 [設定 › 連線 › 檔案](jay:settings#FilesFolder) 裡換）。Jay 從不自己開啟它，是程式檔案時會提醒你。
- 收到世界：卡片上有【匯入到實例】。收到模組清單：【對一下模組】，寫出缺幾個、版本不同幾個。

## 遠端協助
- 在房間裡點一個人，在「和 TA 共享」裡請求看 TA 的螢幕。每次都要對方同意。進行中對方螢幕有紅框，按 Ctrl+Shift+F12 馬上停。

## 值得知道
- 檔案端對端加密，房主和中轉看不到內容。
- 設定 › 連線 › 檔案裡可以打開「核對過的朋友發來的直接收下」（預設關；程式檔案還是要問），也可以限速。
- 遠端協助只給信任的人。Jay 的人永遠不會找你要。給孩子用時只收朋友發來的檔案，也可以關掉遠端協助：看[給孩子用](help:child-mode)。

# 傳檔案和遠端協助

在房間裡可以給某人發檔案，或者請求控制對方的電腦幫 TA 弄。兩樣都必須對方同意。

## 怎麼做
- 發檔案：選一個人，在私聊裡發。對方會看到一張鎖定的卡片，由 TA 決定。
- 收到的檔案只存到「下載/Jay」。Jay 從不自己開啟它，是程式檔案時會提醒你。
- 遠端協助：在房間裡點一個人，在「和 TA 共享」裡點【請求看 TA 的螢幕…】。每次都要對方同意。進行中對方螢幕有紅框，按 Ctrl+Shift+F12 馬上停。

## 出問題了
- 遠端協助只給信任的人。Jay 的人永遠不會找你要。
- 給孩子用時可以關掉遠端協助：看[給孩子用](help:child-mode)。

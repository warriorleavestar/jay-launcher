# 連線

和朋友一起玩：開一個房間，把邀請發給朋友；朋友貼上邀請敲門，你同意後就能進來。

![連線大廳：最上面是加入，下面是開房間和去哪玩](shot:multiplayer-lobby)

連線頁沒有頁籤：沒在房間裡時是大廳，進了房間就是房間。

## 怎麼做
- 加入：把朋友給的碼貼進最上面的框，點按鈕，等對方同意。房間邀請、伺服器邀請、好友碼、網路位址都貼這一個框，按鈕上寫著它要做什麼。
- 開房間：點【開房間】就行，四樣選擇不改也能開。誰能進（只有我邀請的人、我的朋友可以直接敲門、公開）；怎麼連（自動、只走中轉、不經伺服器）；保護（標準、加強、最高）；範圍（只連這個遊戲、整個區域網路）。灰掉的選項下面寫著原因。
- 只走中轉：全部經中轉，房間裡的人互相看不到 IP。會慢一點。朋友的 Jay 太舊、不認這個設定時進不來，要先更新。
- 不經伺服器：按鈕變成【產生加密直連碼】。碼傳給朋友，口令用別的方式告訴 TA。兩台電腦直接相連，連不上時也不會改走中轉。為了查出你的位址，Jay 會詢問設定 › 網路裡列的 STUN 伺服器，它們能看到你的 IP。
- 去哪玩：朋友邀請你的房間、公開房間和你存下的伺服器在一個列表裡，用【全部 / 朋友 / 公開 / 伺服器】篩選。
- 有人敲門：房間裡會出現一張卡片，點【同意】或【拒絕】（Alt+Y / Alt+N）。
- 安全碼：兩邊看到的安全碼一樣，說明沒有人在中間冒充。
- 第一次連線要裝一個連線元件：按鈕會先寫「先安裝連線元件」，點一下裝好，再點一下就開房間或加入。

## 在房間裡
- 最上面是房間名、人數和連線標記（「直連 · 18 ms」或「經中轉 · 82 ms」）。每個人的頭像下面有一條細線：直連和經中轉各一種。核對過的朋友頭像上有勾號。
- 【邀請】：選有效期（10 分鐘、1 天、30 天）和可用次數（1 次、不限），點【產生邀請】。邀請是一張小卡片，可以【複製】或【發給朋友】，點【顯示】才看到碼。不限次數的邀請每次敲門都先問你。30 天的邀請在你以後開的每個房間都能用（現在開著的這個房間裡沒有別的邀請時，它馬上也能用，卡片上會寫），可以隨時作廢。
- 點連線標記看「誰能看到什麼」：一張固定的表，寫誰能看到你的 IP、誰能看到內容。現在適用的那一行標著「現在」。下面有個開關「只走中轉」：打開後房間裡的人看不到你的 IP，延遲會高一些；切換時會重新連一下房間。沒開的時候，就算這會兒經中轉，Jay 也會接著試直連，所以房間裡的人能查到你的 IP。想讓每個房間都這樣，在 設定 › 連線 裡打開「預設只走中轉」。
- 點一個人：看 TA 的安全碼、是不是朋友、怎麼連的。「和 TA 共享」裡有遠端協助、幫 TA 轉發遊戲、讓 TA 經我上網，每一樣打開前都會先問你。
- 【進入遊戲】：加入的人點它，用選好的實例直接進朋友的世界。

## 出問題了
- 連不上：開啟「檢測網路」，它會告訴你卡在哪一步。
- 給孩子用：可以關掉遠端協助、公共網路等，見 [給孩子用](help:child-mode)。

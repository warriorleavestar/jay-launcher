# Jay 裡的詞

Jay 用到的詞，一句白話解釋。

## 詞
- **實例**：一套遊戲，有自己的版本、模組和世界。
- **載入器**：讓模組能執行的東西，比如 Fabric、Forge、NeoForge、Quilt。
- **房間**：你的世界，加上一條只有你邀請的朋友能進的通道。
- **邀請碼**：發給朋友的碼，TA 用它來敲你房間的門。
- **安全碼**：兩邊都能看到的碼。一樣就說明中間沒有別人。
- **好友碼**：在公開房間裡找到朋友的房間。
- **中轉伺服器**：兩臺電腦直接連不上時，幫它們接上的伺服器。
- **直接連上 / 經中轉**：你們的遊戲是直接互通，還是經過中轉伺服器。

# Jay 裡的詞

Jay 用到的詞，一句白話解釋。

## 詞
- **實例**：一套遊戲，有自己的版本、模組和世界。
- **載入器**：讓模組能執行的東西，比如 Fabric、Forge、NeoForge、Quilt。
- **房間**：你的世界，加上一條只有你邀請的朋友能進的通道。
- **邀請**：發給朋友的一串碼，TA 用它來敲你房間的門。裡面沒有你的位址。
- **安全碼**：兩邊都能看到的碼。一樣就說明中間沒有別人。
- **裝置碼**：指向你這臺電腦的碼，朋友用它在公開房間裡找到你的房間。
- **好友碼**：讓別人申請加你為朋友的碼。它不是裝置碼，找不到你的房間。
- **中轉**：兩臺電腦直接連不上時，幫它們轉交資料的伺服器。它看得到你的 IP，看不到內容。
- **直接連上 / 經中轉**：你們的遊戲是直接互通，還是經過中轉。

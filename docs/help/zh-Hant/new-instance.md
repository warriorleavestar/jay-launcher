# 新建實例

新建一套遊戲：選版本，需要模組的話再選一個載入器。

## 怎麼做
- 選版本：預設是最新的正式版。上面的晶片可以切換快照和舊版本。
- 選載入器：Fabric、Forge、NeoForge、Quilt。這個版本不支援的會變灰，並寫明原因。
- **Jay 載入器**：Jay 自己的載入器，排在最後。它建在這個版本的 NeoForge 或 Forge 之上，一個實例裡能混裝 Fabric、Forge 和 NeoForge 的模組（實驗）。名字預設是「1.21.1-Jay」這樣。它還不支援的版本會變灰，並寫出它支援哪些。
- 選了 Fabric、Forge 這些普通載入器時，下面有一個勾選「用通用載入器混裝別的生態的模組」，只在支援的版本上能勾。以後也可以在實例的「設定」頁籤裡打開或關掉。
- 起名字：名字不能和已有的實例重複。
- 點【安裝】。也可以匯入整合包檔案，或者把別的啟動器的遊戲資料夾加進來。
- Esc 關閉面板。

## 出問題了
- 安裝失敗：多數是網路問題，到 [設定 › 下載線路](jay:settings#Source) 換一條線路再試。

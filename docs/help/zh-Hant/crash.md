# 遊戲崩潰了

遊戲崩潰後，實例頁會有「上一局」面板，寫出最可能的原因，並給出當場就能修的按鈕。

## 怎麼做
- 開啟實例。面板裡寫著【很可能】，有時還有【也可能】，以及日誌裡的證據。
- 點原因下面的按鈕：【調高記憶體】、【停用】某個模組、【關掉光影】、【選一個 Java…】或【修復遊戲檔案】，然後再開始遊戲。
- 【還是不行？】裡有[幫我修…](help:fix-helper)和日誌。

## 出問題了
- 沒找到已知原因：[匯出錯誤報告](help:error-report)，發給懂的人看。

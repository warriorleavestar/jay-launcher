# 遊戲庫

遊戲庫是 Jay 的主頁：你裝過的每一套遊戲（實例）都在這裡，最近玩過的排在前面。

![遊戲庫：上面是「繼續玩」，下面是實例卡片](shot:library)

## 怎麼做
- 開始遊戲：點實例卡上的【開始】，或者選中後按 Enter。
- 開啟實例：點卡片本身，進實例詳情頁。
- 固定：在卡片的「⋯」裡點【固定】，它會一直排在前面。
- 搜尋：在上面的搜尋框裡輸入名字或版本號（Ctrl+F）。
- 新建：點【新建實例】（Ctrl+N）。

## 出問題了
- 找不到以前的遊戲：到 [設定 › 儲存](jay:settings#GameDirectory) 看遊戲目錄是不是選對了。

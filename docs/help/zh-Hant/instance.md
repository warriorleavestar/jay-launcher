# 實例詳情

一個實例就是一套獨立的遊戲：自己的版本、載入器、模組、存檔和設定，互不影響。

## 怎麼做
- 開始：點右上角琥珀色的【開始】。
- 頁籤：概覽、模組、資源包、光影、存檔、日誌。用 Alt+數字 切換，或者 Ctrl+Tab。
- 加模組：在「模組」頁籤點【＋ 新增模組】，會帶你去「探索」並只顯示適合這個實例的模組。
- 上一局崩潰了：概覽上會有「上一局」面板，直接點裡面的修復按鈕（調記憶體、停用模組、關光影）。

## 出問題了
- 進不去遊戲：開啟「日誌」頁籤，按 F8 跳到第一條錯誤；或者在「上一局」面板裡點【幫我修…】。

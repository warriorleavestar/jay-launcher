# 看日誌

日誌是遊戲執行時寫下的記錄。遊戲崩潰或者進不去時，從日誌裡能看出原因。

## 怎麼做
- 開啟實例的「日誌」頁籤，選一局執行記錄（新的在前）。
- F8 跳到下一條錯誤，Shift+F8 跳到上一條。
- 用篩選只看錯誤或警告；重複的警告會合成一行，寫著 ×N。
- 匯出錯誤報告：會先給你看要匯出的內容；報告裡不會帶你電腦的使用者名稱。

## 出問題了
- 看不懂：先看頁面上方的「崩潰診斷」那一行，它會用白話寫出最可能的原因。

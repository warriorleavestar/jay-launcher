# 賬號：正版、離線、皮膚站

賬號決定你在遊戲裡叫什麼、用什麼皮膚，以及能不能進正版伺服器。

## 怎麼做
- 微軟賬號（正版）：點【用微軟賬號登入】，按提示在瀏覽器裡登入。
- 離線賬號：只填一個名字，適合單機和區域網。
- 皮膚站賬號：填皮膚站地址、賬號和密碼。
- 切換：點左下角的頭像開啟「我」，在賬號上點【使用】。
- 外觀小人：「我」頁上的小人可以拖曳轉一圈，或者點一下再按 ← →；離線帳號也有一個按名字畫的小人。

## 「我」頁上還有什麼
- **Jay 帳戶**：你在每台電腦上連線用的同一個身分，由抄在紙上的 12 個詞產生。
- **我的好友碼**：傳給朋友，對方就能請求加你。它不能讓任何人進你的房間，也不包含你的位置。
- **我的裝置**：這台電腦和它的安全碼。沒有 Jay 帳戶時，換電腦後朋友要重新加你。
- **外觀**：深淺色、語言，以及去主題包的入口。

## 出問題了
- 微軟登入失敗：檢查電腦時間是否準確；兒童微軟賬號需要家長在 Xbox 家庭設定裡允許多人遊戲。
- 登入憑據只加密儲存在你的電腦上。

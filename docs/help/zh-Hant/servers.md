# 伺服器

一直在線的伺服器有兩種用法：加入朋友執行的伺服器，或者自己開一個 Minecraft 伺服器。

## 怎麼做
- 加入伺服器：把伺服器邀請（以 JAYS2- 開頭）貼到連線頁最上面的框裡，點【加入並存下】。加密的邀請還要填口令。存下的伺服器在「去哪玩」的【伺服器】裡，以後點【進服】。
- 自己開：在開房間卡片下面點【開一個一直在線的伺服器…】，按步驟走【位址 › 準備伺服器端 › 啟動 › 邀請】。Jay 從官方來源下載服務端並校驗，需要時順便下載 Java。
- 執行時可以在控制檯輸入命令。Enter 傳送，↑ ↓ 調出之前的命令。

## 出問題了
- 朋友連不上你的伺服器：路由器或防火牆要放行第一步填的埠。

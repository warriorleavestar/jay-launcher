# 整合包

整合包是一整套模組和設定，裝好就是一個新實例。

## 怎麼做
- 從檔案：在遊戲庫點【新建實例】，選「整合包檔案」，挑一個 .mrpack 或 CurseForge 的 .zip。安裝前 Jay 先給你看裡面有什麼。
- 或者直接把整合包檔案拖到 Jay 視窗上。
- 線上：在「探索」裡選整合包類型，裝一個。
- 分享你自己的：在實例頁選【⋯ 更多 › 匯出模組包…】，選 Modrinth（.mrpack）或 CurseForge（.zip）以及要帶上的內容。

## 出問題了
- CurseForge 上有些檔案不能自動下載，Jay 會列出來，讓你手動下載。

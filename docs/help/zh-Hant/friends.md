# 朋友

朋友是你核對過一次的人。之後互相邀請，不用再經聊天軟體傳碼。

## 怎麼做
- 新增：把你的**好友碼**傳給朋友，或者在【新增朋友…】裡貼上對方的。對方接受後，兩人打電話或當面對四個表情，一樣就成了朋友。
- 看一位朋友：在朋友頁點 TA，能看到 TA 的 Jay 帳戶、每台裝置和安全碼。
- 邀請：先開一個房間，再在朋友頁點【邀請到我的房間】，或者在房間裡點【邀請朋友】。
- 移除朋友或 TA 的某台裝置：【管理朋友】。

## 值得知道
- 好友碼只能讓別人請求加你。它不是邀請，裡面也沒有你的位址。
- 給朋友的邀請加密後經公共網路送達。頁面底部那一行寫著經哪個網路，或者現在沒有連網路。右上角的網路狀態在每一頁都顯示同樣的資訊。
- 雙方都有 Jay 帳戶時，朋友換了新電腦會自動加上，並給你一條提示。沒有的話，每台電腦要分別新增。
- 開啟「給孩子用」後公共網路是關的，所以這一頁是空的。

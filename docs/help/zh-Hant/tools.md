# 工具箱

工具箱裡是不常用但有時很有用的東西：檢查 Jay 更新、修復遊戲檔案、清理快取等。

## 怎麼做
- 從 [設定 › 工具](jay:settings#OpenTools) 開啟，或者在設定頁上面點「工具箱」頁籤。
- 每個工具都寫著它會做什麼；會刪東西的操作會先讓你確認。

## 出問題了
- 檢查更新沒有反應：需要先在 [設定 › 下載與服務](jay:settings#UpdateFeed) 填更新地址；不填 Jay 不會為此連網。

# 快捷鍵

所有操作都能用滑鼠點，下面是對應的快捷鍵。

## 全域性
- Ctrl+K：命令面板（搜例項、設定、頁面）。
- Ctrl+1 / Ctrl+2 / Ctrl+3：遊戲庫 / 發現 / 連線。
- Ctrl+,：設定。
- Ctrl+J：活動中心。
- F1：本頁幫助；Shift+F1：幫助中心。
- Alt+← / Alt+→：返回 / 前進。

## 頁面裡
- Ctrl+F：搜尋當前頁。
- Esc：關閉抽屜、面板或清空搜尋。
- F8 / Shift+F8：日誌裡跳到下一條 / 上一條錯誤。

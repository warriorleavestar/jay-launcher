# 第一次用 Jay

Jay 是一個 Minecraft Java 版啟動器。第一次開啟時有一個兩步的嚮導：先選語言、加一個賬號，再選從哪裡開始玩。

## 怎麼做
- 第 1 步：在右上角換語言；填一個名字加離線賬號，或者點【用微軟賬號登入】。
- 第 2 步：預設裝最新的原版，點【安裝並開始】。也可以點「選別的版本」。
- 嚮導隨時可以點【跳過】，之後在 [遊戲庫](jay:library) 裡點【新建實例】一樣能裝。

## 出問題了
- 名字不能用：只能用英文字母、數字和下劃線，3 到 16 個字。
- 安裝很慢：到 [設定 › 下載來源](jay:settings#Source) 換一個下載來源。

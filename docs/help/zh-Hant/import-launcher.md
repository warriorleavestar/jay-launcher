# 從別的啟動器搬過來

你在別的啟動器裡已有的實例，Jay 可以直接玩，不移動也不復制。

## 怎麼做
- 在遊戲庫點【新建實例】，選「從其他啟動器匯入」。Jay 會列出找到的遊戲資料夾。
- 點【用這個資料夾】；沒列出來就點【選一個資料夾…】。
- Jay 在原地玩這些實例，各自獨立的資料夾保留它們自己的設定。
- 第一次啟動的嚮導也會列出找到的遊戲，【加進遊戲庫】是一樣的。

## 出問題了
- 什麼都沒找到：自己選資料夾（裡面有 versions 的那個）。

# 東西搬到哪了

Jay 的新佈局只有三個地方：遊戲庫、探索、連線。下面是舊頁面去了哪裡。

## 舊頁面 → 新位置
- **啟動** → 遊戲庫：每個實例上的大開始按鈕。
- **下載** → 遊戲庫裡的【新建實例】；模組和整合包在「探索」。
- **資源** → 探索。
- **實例** → 遊戲庫，點一個實例就開啟。
- **日誌** → 每個實例的「日誌」頁籤。
- **工具箱** → 設定 › 工具。
- Ctrl+K 什麼都能找，舊頁面名也行。

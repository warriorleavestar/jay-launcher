# 東西搬到哪了

Jay 的佈局有四個地方：遊戲庫、探索、連線、朋友。下面是舊頁面去了哪裡。

## 舊頁面 → 新位置
- **啟動** → 遊戲庫：每個實例上的大開始按鈕。
- **下載** → 遊戲庫裡的【新建實例】；模組和整合包在「探索」。
- **資源** → 探索。
- **實例** → 遊戲庫，點一個實例就開啟。
- **日誌** → 每個實例的「日誌」頁籤。
- **工具箱** → 清理在 設定 › 儲存，下載 Java 在 設定 › 遊戲預設，檢查更新在 設定 › 關於。
- **賬號** → 「我」：點左下角的頭像。好友碼和你的裝置也在那裡。
- **深淺色和語言**（原來在頭像的選單裡）→ 「我」 › 外觀，設定裡也照舊能改。
- **朋友**（原來在連線設定裡）→ 側欄的「朋友」入口。加朋友、備份和恢復都在那裡。
- **信任的人**（原來是連線設定裡的一張名單）→ 朋友頁裡每個人身上的「TA 敲門直接進」開關。
- **連線設定**（原來是連線頁的一個頁籤）→ 設定 › 連線（邀請、新房間預設、連線元件、緊急斷開）和 設定 › 網路（公共網路、中轉、STUN）。這台電腦的安全碼和裝置碼 → 「我」 › 我的裝置。檢測網路、偵錯模式、診斷報告 → 「連線有問題？」。
- Jay 正在用哪個網路 → 右上角的網路狀態，每一頁都有。
- Ctrl+K 什麼都能找，舊頁面名也行。

# Jay v0.7.0

这是改名为 **Jay** 后的第一个正式版本（上一个正式版本是 v0.5.9，当时还叫 Amber）。合作者早先推过一个 `v0.6.0` 标签，没有发布过正式版，现已不在仓库里；为免混淆，这次直接用 v0.7.0。

> **联机不兼容旧版本**：联机加密和加入房间的方式重做了。房间改用 `JAY2-` 邀请码，直连改用 `JAY2D-` / `JAY2R-` 码，旧的 `AMB-`、`AMBDIRECT`、`AMBREPLY` 码会提示“旧版本”并拒绝。一起联机的人都要升级到 v0.7.0。账号、设置和实例不受影响，直接沿用。

标 **【实验】** 的功能已经做完并通过自动测试，但还没有在真实环境里完整验证。

## 新功能

### 改名为 Jay
- 程序、窗口和图标都换成 Jay（羽毛图标），Windows 程序名为 `Jay.exe`，发布包前缀为 `Jay-`。
- 账号、设置、实例和游戏目录照旧，升级后不用重新登录。

### 联机加密重做【实验】
- **邀请码 + 敲门审批**：房主发 `JAY2-` 邀请码，默认 10 分钟内只能用一次；朋友粘贴后“敲门”，房主在弹出的卡片上同意才能进房间。码里不含房间密钥，转发出去也拿不到房间。
- **每人一把钥匙**：游戏通道和聊天都用每个成员自己的钥匙，聊天发送者由房主核对，成员无法冒充别人。
- **踢人并换钥匙**：被踢的人立即断开、进不了这个房间，他用过的邀请作废，房间随即换一个新网络和新钥匙。
- **直连码不带密钥**：直连改用 `JAY2D-` / `JAY2R-` 码，批准前只能连到“大厅”，进不了房间。
- 码在界面上默认打码，复制后 60 秒自动清除剪贴板；日志和诊断报告里不出现任何密钥或码。
- 已在同一网络内实测（真实 EasyTier、94 项联机自检）；**两台不在同一网络的电脑之间还没实测**。

### Jay 服务器版【实验】
- 新的命令行程序 `jay-server`：开一个只有 Jay 用户、拿到邀请的人才能进的 MC 服务器，VPS 和局域网电脑都可以，Windows / Linux / macOS 都有包。
- 管理员用 `JAYS1-` 邀请码邀请玩家；玩家在联机页的“Jay 服务器”卡片里粘贴一次，之后一键进服。设备身份和用户名绑定，访问密钥换到别的电脑上无效；陌生连接一个字节都收不到。
- 还没有连真实 MC 服务端做过端到端测试。用法见 [server/README.md](../../server/README.md)。

### macOS 和 Linux 版
- 新增 macOS（Apple 芯片、Intel）和 Linux（x64、ARM64）版本。账号令牌在这些系统上用仅当前用户可读的本机密钥加密。
- Apple 芯片版已由合作者真机测过安装、启动、游玩和保存退出。
- **Intel Mac 和 Linux 版【实验】**：自动构建和测试通过，还没有真机验证。完整局域网和出口节点模式仍只支持 Windows。

### 界面改版
- 统一的样式、状态条和错误提示，窗口大小自适应；删除实例、世界和资源可以撤销；日志级别显示和错误跳转更清楚；首次使用有引导。
- 实例页按实例记住标签，启动、更多和新建入口统一；导出整合包改用对话框。
- 资源页补齐加载中、无结果、失败、慢速和安装中的状态；翻页时保留详情，可选依赖可以勾选安装。
- 界面支持简体中文、繁體中文、English、日本語四种语言。
- 联机页加了“怎么联机”引导，两种方式各自需要什么一目了然；高级选项默认折叠；贴错的码会自动认出来并提示。

### 模组与整合包
- 整合包兼容更多格式：PCL 带启动器的包、压缩的 `.minecraft` 文件夹、多套了一层文件夹的包，并读取 PCL / HMCL 的版本隔离设置。
- CurseForge 上作者关闭第三方分发的文件不再被偷偷下载，改为给出官网手动下载入口。
- 修复模组检查把 Fabric API 子模块误报为“缺少前置”的问题（#22）。
- **模组烘焙【实验，默认关闭】**：启动前用本机通用加载器预处理模组并缓存，只支持 1.21.1 的 Fabric、Quilt 和原版；失败会提示并可一键不烘焙重新启动。需要另外准备加载器，普通用户不用打开。

### 联机其他改进
- 出口节点：成员的上网流量全部经房主的隧道，带防泄漏规则；修复直连房间部分按钮要重开页面才出现的问题。
- 完整局域网模式不再把房间密钥写到磁盘上。
- 新增无痕模式（默认关）：游戏日志不记录聊天内容。

### 安全
- 两轮安全边界修复（进程边界、项目链接、账号密钥文件权限等），并补了回归测试。

### 其他
- 仓库地址改为 [warriorleavestar/jay-launcher](https://github.com/warriorleavestar/jay-launcher)（旧地址会自动跳转）。
- 新实例第一次启动时按系统语言预设游戏语言（不改已有的游戏设置）。
- 新增问题反馈和功能建议的 Issue 模板。

## 已知问题

- 被房主踢出的人，界面有时会显示“正在连接房主”，而不是“已被移出房间”。这只是提示文字不对，他确实已经断开、也进不了房间，安全上没有影响。
- 旧版（v0.5.9 及更早）的房间码和直连码不能在 v0.7.0 里用，反过来也一样。
- macOS / Linux 版没有代码签名；Windows 版也没有，SmartScreen 拦截时点“更多信息 → 仍要运行”。

# 手机通过联机成员的网络上网

Windows 上可以把正在使用的远端网络出口共享给电脑的移动热点：

`手机 → 本机移动热点 → Jay 联机隧道 → 提供出口的成员 → 互联网`

手机只需连接 Wi-Fi，不需要安装 Jay。本机仍然需要互联网连接来维持隧道，提供出口的电脑也需要保持开机、联网。

## 使用

1. 两台电脑在完整局域网模式下建立联机连接。提供网络的一方需要开启允许其他成员使用自己的网络出口。
2. 在本机选择该成员作为出口，先确认本机可以通过对方网络访问互联网。
3. 在联机页的手机热点卡中打开 Windows 移动热点设置，打开热点并设置 Wi-Fi 名称和密码。
4. 返回 Jay，开始共享。只有 Windows 读回的共享配置与本次隧道一致时，界面才显示共享已配置。
5. 手机连接这个热点。必要时断开手机 Wi-Fi 后重新连接，让手机重新获取地址和 DNS。
6. 停止共享、退出房间或切换出口时，本次共享会停止，并尝试恢复之前的热点上游。手机随后可能通过原来的本地网络上网。切换出口后需要重新开启共享。

“共享已配置”表示 Windows 配置已确认，不表示已经验证远方电脑可以访问每个网站。打洞失败、对方退出或对方网络异常仍可能导致无法上网。

## 支持范围

- 仅 Windows，且本机已在完整局域网模式使用远端出口。
- 只接管唯一已开启的 Windows 移动热点，保留同一个热点接口。不会把以太网共享、任意 Wi-Fi 网卡或其他 VPN 当作手机热点。
- 多个共享接口、自定义 ICS 端口映射、无法确认接口身份或驱动不支持共享时，会拒绝配置并报告原因。
- 本功能当前使用 IPv4。热点共享和本机出口会话存活期间，临时规则限制热点经所选隧道转发，并阻止热点 IPv6 转发；会话清理时会撤销这些规则。
- 共享由当前联机会话管理，不保存“下次启动自动共享”的开关。若 Windows 设置或其他程序改变共享，本功能会停止，不会持续强制改回。

## 验证和恢复

首次使用时，先关闭手机蜂窝数据或 Wi-Fi 助理等自动切换网络功能，再检查手机能否打开网页、解析域名，以及手机的 IPv4 出口是否与提供网络的电脑一致。共享仍开启时，检查手机是否绕过所选出口使用本地网络或 IPv6。

需要分开验证远端暂时不可达和本机会话结束两种情况。远端暂时不可达、本机共享会话仍存活时，手机可能暂时无法通过隧道上网；本机停止共享、切换出口、核心异常退出或启动器退出触发清理时，会尝试恢复原来的热点上游，手机可能重新通过本地宽带上网。因此本功能不提供“对方断开后手机持续断网”的保证。需要保持手机断网时，请关闭电脑热点，并关闭手机自身的其他上网方式。

守护清理会尝试恢复原共享，但恢复也可能失败。若管理员守护进程被强制结束、电脑掉电，或 Windows 自己改动了共享配置，不能保证原共享立即恢复。此时在 Windows 移动热点设置里关闭热点，重新选择原来的互联网连接并再次打开；不要继续把失效的 Jay 虚拟网卡作为共享来源。

自动化验证使用模拟 COM、网卡和网络过滤接口，覆盖共享切换、失败回滚、接口变更、断开以及界面状态。真实无线驱动、ICS 与手机 DHCP/DNS 的兼容性仍需在目标设备上完成端到端验证。
